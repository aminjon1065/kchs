# Демонстрационные данные

Генератор детерминированный: один и тот же seed даёт одинаковый результат, что
позволяет опираться на данные в e2e-сценариях.

## Что создаётся

`pnpm db:seed` (профиль `demo`, по умолчанию):

| Сущность | Объём |
|---|---|
| Пользователи | 61 (администратор + `user001…user060`) |
| Подразделения | 22 в четырёх уровнях: комитет → управления → отделы → региональные |
| Должности | 10 (от председателя до специалиста) |
| Пространства | 3 общих (`org`, `flood-2026`, `digital-map`) + по одному на подразделение + личные |
| Разделы и файлы | «Регламенты», «Формы и шаблоны», «Сводки», «Материалы совещаний» |
| Роли | 7 системных со способностями |

`pnpm db:seed --profile=minimal` создаёт только администратора, должности и
оргструктуру — для чистой установки.

`pnpm db:seed --reset` предварительно удаляет данные (схему не трогает).

## Учётные данные

Задаются переменными окружения; значения по умолчанию — только для локальной
разработки и подлежат смене при первом входе в боевой установке.

| Переменная | По умолчанию |
|---|---|
| `SEED_ADMIN_LOGIN` | `admin` |
| `SEED_ADMIN_PASSWORD` | `Kchs!Start-2026-7q` |
| `SEED_USER_PASSWORD` | `Kchs!Work-2026-3v` |

## Персональные данные

Все фамилии, имена и должности — синтетические, собраны генератором из словарей
в `apps/api/src/seed/data.ts`. Совпадения с реальными людьми случайны.

## Территории и геометрии — фаза 1

Справочник территорий (страна → области → районы) и границы появятся вместе с
модулем данных. Источник и лицензия фиксируются здесь до загрузки (риск R13
в `docs/04-delivery/05-risks-and-open-questions.md`): предпочтение отдаётся
официальным открытым данным с явно указанными условиями использования.

| Набор | Источник | Лицензия | Статус |
|---|---|---|---|
| Административные границы | — | — | не загружены (фаза 1) |
| Базовая карта (PMTiles) | — | — | не загружены (фаза 2) |
