# 0207. Запуск без сети: оболочка в служебном потоке, профиль на устройстве, сводка, открытая без сети

Статус: Принято
Дата: 2026-10-13

## Контекст

ADR-0204 сделал очередь сдачи сводок: сдача без сети ложится в IndexedDB и уходит сама. Но
работала очередь, только пока страница открыта. Холодный старт без сети отложили из-за
CSP: `index.html` несёт nonce запроса и отдаётся с `no-store` (ADR-0043). Служебный поток
регистрировался только ради push (ADR-0094) и там, где push нет, не появлялся вовсе.

Сценарий концепт-ноты (§4.2) — выезд в горный район, где связь пропадает на часы.
Сотрудник открывает портал на телефоне без сети, заполняет сводку и сдаёт её. Сводка
уходит, когда связь вернётся. Владелец 13.10.2026 велел сделать это сейчас (N110).

Что мешало, кроме CSP:

- без ответа `/me` приложение бесконечно показывало «Загружаем рабочее пространство»;
- сводку открывал только сервер (`POST /forms/{id}/submissions`): период, не открытый при
  связи, без сети было не заполнить;
- карточка формы (`GET /forms/{id}`) не запоминалась — экран формы без сети не открывался.

## Решение

1. **Служебный поток регистрируется всегда.** Регистрация — при входе в оболочку, где есть
   `serviceWorker`, независимо от push. Страница входа поток не регистрирует: без входа
   работать без сети нечего.
2. **Кэш оболочки, а не данных** (`apps/web/public/sw.js`):
   - навигация по путям SPA — «сеть первой». Ответ сети отдаётся как есть и запоминается
     (`kchs-shell-v1`) вместе со своими заголовками. Из кэша страница отдаётся только при
     сетевой ошибке. Переадресации и не-HTML не запоминаются;
   - `/assets/*` — «кэш первым» (`kchs-assets-v1`, до 400 файлов, старые вытесняются). Имя
     файла несёт хеш содержимого, поэтому файл не меняется;
   - `/api/`, `/ws/`, `/collab/` поток не трогает. Справочники для работы без сети
     запоминает само приложение, по сотруднику (`cachedFetch`, ADR-0204). Ответов API в
     кэше потока нет, и после выхода в нём не остаётся данных сотрудника;
   - при активации поток сам запрашивает `/` и запоминает файлы, на которые ссылается
     страница. Первая страница грузилась раньше, чем поток начал её обслуживать.
3. **nonce CSP в ответе из кэша.** Заголовок CSP и `<meta name="csp-nonce">` у
   запомненного ответа — от одного запроса. Caddy подставляет `{http.request.uuid}` в
   оба места, а поток хранит ответ целиком. Документ из кэша получает политику из
   заголовков этого ответа, и nonce совпадает. Проверено на сборке через Caddy с тем же
   Caddyfile: перезагрузка без сети отдана потоком (200), nonce в заголовке и в `<meta>`
   одинаковы, стили применены, нарушений CSP нет.

   Повторный nonce не ослабляет защиту:
   - скрипты разрешены только как свои файлы (`script-src 'self'`), nonce на них не
     действует;
   - nonce открывает только `<style>`, и только на устройстве, где страница уже лежит.
     Чтобы воспользоваться им, нужна инъекция разметки. React её не допускает, а для
     того, кто может внедрить разметку на устройстве, nonce и так виден в DOM;
   - кэш срабатывает только без сети. При связи страница всегда приходит с новым nonce.

   `no-store` в ответе Caddy по-прежнему защищает от HTTP-кэша браузера и посредников.
   Хранилище кэша служебного потока — явное решение приложения, а не HTTP-кэш.
4. **Профиль на устройстве.** Ответ `/me` запоминается в IndexedDB без токена CSRF. При
   сетевой ошибке и ответах 408, 429, 502–504 `meQuery` отдаёт запомненный профиль, и
   оболочка открывается: очередь знает, чья она, а справочники — чьи показывать. Профиль
   стирается:
   - при выходе — до запроса выхода;
   - при 401, то есть когда сессии больше нет;
   - сам через 7 дней без связи.

   Профиль не запоминается, пока сотрудник обязан сменить пароль или подключить второй
   фактор. Если без сети на устройстве никого нет, приложение показывает «Нет сети» с
   объяснением и кнопкой «Повторить» вместо бесконечной загрузки. Отправка, получившая 401
   при досылке, не становится «не сдана», а ждёт нового входа.
5. **Сводка, открытая без сети.** Открытие периода идёт через `cachedFetch`: без сети
   отдаётся прежний ответ сервера. Если период ещё не открывали, приложение заводит
   местный черновик с ключом `local:<uuid>`. Сдать его можно только через очередь:
   - запись очереди несёт период и назначение;
   - досылка сначала открывает сводку на сервере (повтор открытия возвращает ту же), затем
     грузит снимки (ADR-0208) и сдаёт с прежним ключом идемпотентности;
   - экран узнаёт свою сдачу по `localId` записи.

   Черновик без сети не сохраняется: черновики хранит сервер. Экран говорит об этом и
   предлагает сдать. Список и карточка форм тоже идут через `cachedFetch`.
6. **Экраны сводок — заранее.** Модуль объявляет код, нужный без сети: свойство `offline`
   в `registerModule`, сейчас — экраны форм. Через 5 секунд после входа приложение
   загружает этот код и словари модуля (ADR-0191), затем называет потоку все уже
   загруженные файлы сборки (`performance.getEntriesByType('resource')`), а поток кладёт
   их в кэш. Без этого при холодном старте без сети не нашлось бы чанка экрана или
   словаря, которые при связи не открывали. Неймспейсы, нужные этому коду, проверяет
   `app/namespaces.test.ts` в области модуля.

## Альтернативы

- **Workbox и предварительный кэш всей сборки по манифесту.** Отклонено. Сборка весит
  мегабайты (карты, графики, редакторы), и скачивать её целиком на каждый выпуск по
  мобильной связи дорого. Кэш по факту загрузки и подготовка экранов сводок покрывают
  сценарий без новой зависимости.
- **Убрать nonce из страницы для кэша** (стили `'unsafe-inline'`). Отклонено: это
  ослабляет CSP для всех ради редкого случая.
- **Страница из кэша — «кэш первым».** Отклонено. Открытая при связи страница должна
  приходить с новым nonce и новой версией сборки.
- **Background Sync для очереди.** Отклонено в ADR-0204: Safari его не поддерживает.
- **Профиль без срока.** Отклонено. Сессия, отозванная администратором, должна закрыть и
  работу без сети. Без связи устройство об этом не узнает, а неделя ограничивает окно.

## Последствия

- Изменены `apps/web/public/sw.js` и `shared/push/client.ts` (регистрация).
- Новые модули `shared/offline/profile.ts` и `warmup.ts`, а также `meQuery`, экран
  «Нет сети» в `app.tsx`, выход и 401.
- Очередь: в записи появились `open` и `localId`, досылка открывает сводку на сервере.
  IndexedDB `kchs-offline` версии 2 получила хранилище снимков (ADR-0208).
- Сценарий Playwright `forms-offline.spec.ts`:
  - «связь пропала после открытия периода»;
  - холодный старт без сети — только на собранном приложении (профиль `app`). На сервере
    разработки Vite страница грузит исходники, и тест пропускается.
- Служебный поток в разработке перехватывает только навигации и `/assets/*`, поэтому
  HMR Vite (`/@vite`, `/src`, WebSocket) он не трогает.
- Не сделано:
  - подложка района на устройстве (PMTiles) — по-прежнему отдельной работой (ADR-0204);
  - донесения без сети — после ключа идемпотентности у создания документа.
