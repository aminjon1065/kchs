# 0018. Tiptap + Yjs/Hocuspocus
Статус: Принято. Дата: 2026-09-17

## Контекст
Страницы знаний, тетради, протоколы, описания требуют богатого текста с совместным редактированием; сообщения — того же формата без совместности.

## Решение
Tiptap (ProseMirror) как единый редактор; Yjs через Hocuspocus для объектов с совместным редактированием; хранение JSON и Yjs-состояния.

## Альтернативы
Lexical/Slate (меньше готовых расширений); собственные CRDT (нет).

## Последствия
Единый формат `body` (Tiptap JSON) везде; безопасный рендерер с белым списком узлов; права на уровне collab-сервера.
