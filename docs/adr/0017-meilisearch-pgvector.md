# 0017. Meilisearch + pgvector
Статус: Принято. Дата: 2026-09-17

## Контекст
Мгновенный поиск с опечатками и фасетами по объектам, файлам и сообщениям; семантический поиск и RAG.

## Решение
Meilisearch как индекс с фильтром по принципалам; pgvector для эмбеддингов (bge-m3 в engine); гибридная выдача.

## Альтернативы
Postgres FTS (слабее ранжирование/опечатки, но нулевая эксплуатация — остаётся вариантом за портом `SearchIndex`); OpenSearch (тяжёлый); Typesense (сопоставим, меньше экосистема).

## Последствия
Ещё один сервис (лёгкий); индекс перестраивается из Postgres; права дублируются в индексе (aclPrincipals) с пост-проверкой.
