# 0062. Откат датасета к прежней версии: отмена по истории строк и импорту «дополнить»

Статус: Принято
Дата: 2026-09-19

## Контекст

06-analytics-engine.md «Версии»: «откат (создаёт новую версию из старой)»; бэклог P1-E01 S04 —
«КП: откат создаёт новую версию». Версия датасета (`dataset_versions`) хранит происхождение,
счётчики и ссылку на импорт, но не строки: снимков Parquet (`parquet_key`) в фазе 1 нет, а
история строк `ds.h_*` (ADR-0051) не была связана с номером версии — по ней нельзя было сказать,
какие записи отменить.

## Решение

1. **История строк помечается номером версии.** Столбец `dataset_version` в `ds.h_*`
   (с индексом); правки строк сначала поднимают версию, затем пишут историю с её номером.
   Таблицы, созданные раньше, дополняются при старте API (`upgradeHistoryTables`,
   идемпотентно) — отдельная миграция не нужна, таблицы динамические.
2. **Откат — отмена изменений после целевой версии, от новых к старым**, в одной транзакции под
   блокировкой строки датасета: вставка → мягкое удаление, удаление → восстановление, правка →
   прежние значения полей, которые есть в схеме. Каждая отмена пишется в историю строки с номером
   новой версии `rollback`, поэтому откат отката работает так же. Импорт «дополнить» отменяется
   по `_import_id` его строк (мягкое удаление с записью в историю).
3. **Что откат не пропускает** (409 с номером версии и причиной): импорт «заменить»,
   «обновить по ключу» и «синхронизировать» (прежних значений нет — повторите импорт нужного
   файла), смена схемы, создание датасета, правки без полной истории — число записей истории
   версии меньше её счётчиков (история была выключена или версия создана до пункта 1). Также
   отказ, если история датасета выключена или идёт импорт. Прежнее значение ключа, занятое
   другой строкой (мягко удалённые строки держат ключ), — 409, транзакция откатывается целиком.
4. **API и права:** `POST /datasets/:id/versions/:number/rollback` → запись новой версии;
   право `manage`. Политики строк и столбцов управляющего откат не сужают: он и так может их
   изменить. Событие `dataset.rolled_back {version, target, from}`; счётчики версии — сколько
   строк восстановлено, изменено и удалено при отмене.
5. **Экран:** кнопка «Откатить» у прежних версий на вкладке «Версии» (управляющим), с
   подтверждением; причина отказа — в уведомлении.

## Альтернативы

- **Снимок строк на каждую версию (Parquet в S3)** — откат через любой импорт, но стоимость
  хранения и записи на каждую правку ячейки; вернуться к нему вместе с колоночным слоем
  (06-analytics-engine.md «Большие датасеты»), тогда пункт 3 ослабнет для импортов.
- **Отмена по времени (`changed_at` истории ≥ даты версии)** — без нового столбца, но неточна при
  одновременных транзакциях и не отличает отмену отката от исходных правок.

## Последствия

- Правки строк и дозагрузки откатываются без копий данных; стоимость — по числу отменяемых
  записей истории.
- Версии до обновления (без номера в истории) откатить нельзя — это видно по причине отказа.
- Просмотр строк «как было» на версии — отдельная задача: те же записи истории, прочитанные без
  изменения таблицы.
