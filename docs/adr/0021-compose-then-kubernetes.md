# 0021. Docker Compose для S1, Kubernetes/Helm для S2+
Статус: Принято. Дата: 2026-09-17

## Контекст
Первое развёртывание — один сервер on-premise; рост — до тысяч пользователей.

## Решение
Compose с профилями как основной способ S1; Helm-чарт для S2 с внешними/операторными PostgreSQL, Redis, MinIO; одинаковые образы.

## Альтернативы
Сразу Kubernetes (перегрузка для одной машины); Nomad/Swarm (менее распространены).

## Последствия
Два описания инфраструктуры в репозитории; общие healthchecks и конфигурация через окружение.
