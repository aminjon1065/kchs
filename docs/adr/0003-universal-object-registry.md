# 0003. Универсальный реестр объектов
Статус: Принято. Дата: 2026-09-17

## Контекст
Связи, права, обсуждения, поиск, избранное, корзина и открытие во вкладке нужны для десятков типов сущностей. Реализация по типу ведёт к дублированию и несогласованности.

## Решение
Таблица `objects` с общим UUID для всех значимых сущностей; таблицы модулей ссылаются на неё; реестр типов в коде описывает поведение типа; ядро реализует общие механизмы один раз.

## Альтернативы
Полиморфные ссылки без реестра (нет единого ID/прав); дублирование механизмов в модулях.

## Последствия
Каждое создание идёт через `ObjectService`; лишний JOIN для списков (компенсируется денормализацией `meta`); универсальные экраны и компоненты.
