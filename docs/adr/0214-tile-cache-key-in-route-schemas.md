# 0214. Ключ кэша тайлов в схемах маршрутов; шаблоны тайлов MapLibre — по таблице

Статус: Принято
Дата: 2026-10-13

## Контекст

Клиент web обращается к API только по таблице маршрутов (ADR-0188): путь, параметры и строка
запроса проверяются компилятором. Исключением оставались три адреса «вне клиента с пометкой»:
шаблон тайлов слоя (`/gis/layers/:id/tiles/{z}/{x}/{y}.pbf?v=…&lv=…`), шаблон тайлов
слоя-ссылки и источник GeoJSON его объектов. Их собирали строкой по двум причинам:

- MapLibre ждёт в шаблоне заполнители `{z}/{x}/{y}` без кодирования, а `apiUrl` кодирует
  параметры пути и проверяет их типом маршрута (числа);
- ключи кэша браузера — версия данных `v` и версия слоя `lv` — в схемах строки запроса не
  были описаны (`lv` у тайлов слоя, `v` у слоя-ссылки), и запрос со схемой их бы не пропустил
  компилятором клиента.

Разбор укрепления (`07-architecture-hardening.md` §5.0б) оставил это хвостом этапа 3.

## Решение

1. **Ключи кэша — в контракте.** `LayerTileQuery` получил `lv` (версия слоя) рядом с `v`
   (версия данных); у маршрута тайлов слоя-ссылки появилась строка запроса
   `ServiceLayerTileQuery` с `v`, у его объектов `ServiceLayerFeaturesQuery` — тоже `v`. Все
   необязательные: сервер их не читает, они только меняют адрес после правки, чтобы кэш
   браузера (`max-age` тайлов) не отдал старое.
2. **`tileUrl(path, { params, query })`** в `shared/api/link.ts` — шаблон тайлов по маршруту
   таблицы: тип ограничивает путь маршрутами `…/:z/:x/:y…`, параметры пути — без `z`, `x`,
   `y`, строка запроса — по схеме маршрута. Заполнители `{z}/{x}/{y}` подставляются и
   возвращаются без кодирования; адрес полный — тайлы грузит воркер MapLibre.
3. Источник GeoJSON слоя-ссылки строится `apiUrl`, как любая ссылка на GET-маршрут.

## Альтернативы

- **Оставить строки с пометкой.** Отклонено: правка маршрута (переименование, новый параметр)
  не ломала бы сборку, а тихо давала 404 на карте.
- **`apiUrl` с разрешением заполнителей.** Отклонено: тип параметров пути у `apiUrl` — из
  схемы маршрута (`z` — число); особый случай в общем помощнике размыл бы его проверку.

## Последствия

- Контракт: новые необязательные поля строки запроса — совместимо (`contracts:compat`).
- Адресов API вне клиента с пометкой в web больше нет (`api-calls.mjs`: 3 → 0).
- Шаблон тайлов подложки строит сервер (`basemap-service.ts`); его ключ `v` в схему маршрута
  не внесён — веб этот адрес не собирает.
