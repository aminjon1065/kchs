# 0019. Собственная аутентификация + OIDC/LDAP-интеграции
Статус: Принято. Дата: 2026-09-17

## Контекст
Продукту нужна собственная модель пользователей и оргструктуры, свой UX входа/MFA/восстановления, поддержка корпоративных каталогов.

## Решение
Аутентификация в приложении (argon2id, TOTP, WebAuthn, сессии); OIDC-клиент для SSO; LDAP-синхронизация и bind; всё — стандартные библиотеки.

## Альтернативы
Keycloak (лишний сервис и дублирование пользователей; подключается позже как IdP при необходимости); Auth.js (ориентирован на Next).

## Последствия
Ответственность за безопасность входа (покрыта чек-листом); отсутствие внешней зависимости.
