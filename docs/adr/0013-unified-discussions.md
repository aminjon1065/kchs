# 0013. Единые обсуждения: комментарии = сообщения
Статус: Принято. Дата: 2026-09-17

## Контекст
Комментарии к объектам и чаты дублируют механику: упоминания, вложения, реакции, треды, уведомления, поиск.

## Решение
Одна модель `conversations/messages`; у каждого обсуждаемого объекта — беседа `kind='object'`; чаты — беседы других видов; обсуждения объектов видны в модуле «Чаты».

## Альтернативы
Отдельная таблица комментариев (две реализации, разрыв контекста).

## Последствия
Один компонент ленты/композера; права обсуждения выводятся из прав объекта; системные сообщения в единой ленте.
