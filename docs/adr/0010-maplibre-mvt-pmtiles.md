# 0010. MapLibre GL JS, MVT из PostGIS в приложении, PMTiles-базовые карты
Статус: Принято. Дата: 2026-09-17

## Контекст
Карты должны быть быстрыми, красивыми, самодостаточными (оффлайн) и подчиняться правам на строки.

## Решение
MapLibre GL JS на клиенте; векторные тайлы генерируются эндпоинтом API (`ST_AsMVT`) с политиками строк, кэшем, кластеризацией и генерализацией; базовые карты — PMTiles из Planetiler в MinIO; для S2 — Martin для статичных тяжёлых слоёв за прокси с проверкой прав.

## Альтернативы
Leaflet (растровое мышление, слабее для больших данных); OpenLayers (мощный, но тяжелее для премиального UI); GeoServer (Java, тяжёлая эксплуатация); внешние облачные базовые карты (зависимость от интернета).

## Последствия
Полный контроль прав в тайлах; необходимость кэша и генерализации; пайплайн PMTiles в эксплуатации.
