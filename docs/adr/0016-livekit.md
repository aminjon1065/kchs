# 0016. LiveKit как медиасервер
Статус: Принято. Дата: 2026-09-17

## Контекст
Нужны встроенные звонки и конференции с демонстрацией экрана, гостями, записью, в собственном интерфейсе, self-hosted.

## Решение
LiveKit server + Egress (запись) + встроенный TURN; клиентский SDK с собственным UI; вебхуки в API.

## Альтернативы
Jitsi (готовый продукт, трудно встроить в собственный UX); mediasoup/Janus (низкоуровневые, много кода); облачные сервисы (зависимость и данные вовне).

## Последствия
Дополнительный сервис с UDP-портами и TURN/TLS; масштабирование узлами; запись в S3.
