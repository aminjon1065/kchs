# 0023. Собственная дизайн-система на Tailwind + Radix
Статус: Принято. Дата: 2026-09-17

## Контекст
Требование премиального, плотного и согласованного интерфейса в обеих темах с полным контролем деталей.

## Решение
Токены (json → CSS-переменные → Tailwind), Radix Primitives для доступности и поведения, собственные компоненты в `packages/ui` по паттерну shadcn, Storybook с визуальными тестами.

## Альтернативы
MUI/Ant/Mantine (узнаваемый чужой вид, борьба со стилями, плотность); только Tailwind без примитивов (доступность вручную).

## Последствия
Начальная инвестиция в компоненты (фаза 0); полный контроль качества; линт на произвольные значения.
