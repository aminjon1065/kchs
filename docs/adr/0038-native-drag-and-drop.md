# 0038. Доска: нативное перетаскивание и перенос с клавиатуры

Статус: Принято
Дата: 2026-09-18

Контекст: `05-risks-and-open-questions.md` §3 оставляет открытым выбор библиотеки
drag-and-drop (рекомендован `@dnd-kit`). Первый потребитель — режим «доска»
CollectionView (P0-E12 S03), дальше доска задач с переходами статусов (P1-E08).

Решение: `KanbanBoard` в `packages/ui` использует нативный HTML5 DnD — перенос
карточки между колонками мышью, подсветка допустимых колонок (`canMove` — переходы
статусов задают модули). С клавиатуры карточка переносится Alt+← / Alt+→
в соседнюю колонку, Enter открывает её. Сортировка карточек внутри колонки
не поддерживается — порядок задаёт сортировка представления.

Альтернативы: `@dnd-kit` — сенсоры касаний и сортировка внутри колонки ценой
зависимости и заметного объёма кода; вернёмся к нему, если понадобится ручной
порядок карточек или перетаскивание на сенсорных экранах (нативный DnD там не работает).

Последствия: на телефонах и планшетах доска переносит карточки только через
карточку/меню действий модуля; клавиатурный путь одинаков везде.
