# 0012. Собственный лёгкий движок процессов
Статус: Принято. Дата: 2026-09-17

## Контекст
Маршруты документов, ознакомления, модерация правок и автоматизации с ожиданием требуют оркестрации с назначениями по оргструктуре, сроками и таймерами.

## Решение
Декларативные определения (JSON) с типами шагов, параллельными ветвями, условиями, таймерами и выражениями назначений; исполнение в ядре на событиях и отложенных заданиях; версионирование определений.

## Альтернативы
Camunda/BPMN (Java, тяжёлая интеграция, избыточная нотация для пользователей); Temporal (отличная надёжность, но дополнительная инфраструктура и код-ориентированные workflow — плохо для конструктора маршрутов администратором).

## Последствия
Полный контроль над UX маршрутов; ответственность за идемпотентность и восстановление; Temporal остаётся планом Б для сложных оркестраций.
