# 0020. Одна организация на инсталляцию
Статус: Принято. Дата: 2026-09-17

## Контекст
Корпоративная/государственная платформа с требованиями изоляции данных; неизвестна потребность в обслуживании нескольких организаций из одной установки.

## Решение
Без `tenant_id`; изоляция организаций — отдельными инсталляциями; пространства — единица разграничения внутри организации; конфигурация переносима пакетами.

## Альтернативы
Многоарендность с первого дня (усложнение всех запросов, кэшей, индексов и прав без подтверждённой потребности).

## Последствия
Проще всё; при появлении требования — отдельные инсталляции + центральная агрегация (S3) или миграция на `tenant_id` как крупный проект.
