# 0015. BullMQ как система заданий для TypeScript и Python
Статус: Принято. Дата: 2026-09-17

## Контекст
Импорт, экспорт, рендеринг, расшифровка, индексация, таймеры процессов — фоновые задания в TS-worker и Python-engine.

## Решение
BullMQ поверх Redis; официальная Python-библиотека `bullmq` в engine; реестр заданий в Postgres для UI и истории.

## Альтернативы
Celery (только Python); pg-boss (только Node); отдельный брокер.

## Последствия
Единые очереди для двух языков; прогресс через Redis pub/sub; Redis с AOF.
