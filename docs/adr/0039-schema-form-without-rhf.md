# 0039. SchemaForm — управляемая форма на валидации packages/fields, без react-hook-form

Статус: Принято
Дата: 2026-09-18

Контекст: `18-tech-stack.md` рекомендует для форм react-hook-form + zod (вспомогательная
библиотека, статус «Рекомендовано»). SchemaForm строит форму из схемы полей
(`contracts/field-types.md`): проверка, условная видимость и обязательность уже
реализованы в `packages/fields` и используются сервером (импорт, API строк датасетов).

Решение: `SchemaForm` и `InlineProperties` в `packages/ui` — управляемые компоненты:
значения хранит вызывающий код, проверка — `validateValues` из `packages/fields`
(та же, что на сервере), сообщения локализуются по коду и границам проверки
(`FieldIssue.params`). Пустая строка в нетекстовом поле считается «не задано»,
`requiredIf` участвует в проверке. Контролы, которым нужны данные приложения
(люди, объекты, территории, файлы, геометрия), передаются через `renderControl`.

Альтернативы: react-hook-form — регистрация полей и неуправляемые инпуты дают
выигрыш на больших ручных формах, но схема здесь динамическая, а проверка должна
совпадать с серверной; обёртка RHF над `validateValues` добавила бы слой без пользы.

Последствия: одна реализация правил проверки для клиента и сервера; для очень
больших форм (сотни полей) при необходимости — виртуализация групп.
