# 0022. Серверный рендеринг через Playwright
Статус: Принято. Дата: 2026-09-17

## Контекст
Отчёты, печатные формы, снимки карт и дашбордов должны выглядеть как на экране и содержать те же графики/карты.

## Решение
Engine поднимает headless Chromium (Playwright), открывает печатные маршруты web с сервисным токеном и печатает PDF/PNG; DOCX — docxtpl со вставкой изображений.

## Альтернативы
Серверные библиотеки рендеринга графиков/карт (расхождение с экраном, maplibre-native сложен в сборке); клиентская генерация PDF (ненадёжно для расписаний).

## Последствия
Единый визуальный результат; ресурсоёмкость Chromium в engine (пул, лимиты); печатные маршруты как часть web.
