# 0009. Графики через ChartSpec с рендером ECharts
Статус: Принято. Дата: 2026-09-17

## Контекст
Графики создаются пользователями, дашбордами, отчётами и ИИ; нужны интерактивность, большие данные, темы и независимость от библиотеки.

## Решение
Собственный декларативный `ChartSpec` (без hex-цветов, с семантическими палитрами) → компилятор в option Apache ECharts; тема из токенов.

## Альтернативы
Vega-Lite (элегантно, но слабее по производительности и интерактиву); Recharts/visx (мало типов, ручная работа); Plotly (тяжёлый, стиль).

## Последствия
Единое описание графиков в дашбордах/тетрадях/отчётах; возможность сменить рендерер; тесты снимками.
