# 0066. Базовые карты: сборка PMTiles без морских полигонов, реестр `basemap`, стиль и прокси через API

Статус: Принято
Дата: 2026-09-19

## Контекст

P2-E01 S04 (`03-backlog.md`): «PMTiles-скрипт, реестр, стили light/dark, прокси растров».
`07-gis-engine.md` §5 и ADR-0010 задают векторную подложку PMTiles из Planetiler в MinIO с
отдачей Range-запросами, стили `light`/`dark`/`muted` по схеме OpenMapTiles в цветах
дизайн-системы, растровые XYZ через прокси API (скрытие ключей, кэш) и реестр `basemaps` с
подложкой по умолчанию; `01-vision.md` (A6) — самодостаточность без интернета, включая шрифты.
`05-data-model.md`: `basemaps(id pk → objects, kind, url, style jsonb, attribution, min_zoom,
max_zoom, is_default)`; способность `gis.basemaps.manage` уже есть у ролей `system_admin` и
`gis_admin`. Открытыми оставались объём сборки на машине разработки, раскладка хранилища, как
клиент получает стиль и тайлы с проверкой прав, где хранится ключ растрового сервера и что
показывать, пока векторной подложки нет.

## Решение

1. **Сборка** — `infra/basemaps/build-pmtiles.sh`: Planetiler 0.10.2 в Docker с профилем
   OpenMapTiles (как в ADR-0010), выгрузка Geofabrik страны (`KCHS_BASEMAP_AREA`, по умолчанию
   `tajikistan`), охват `60,33,81,45` — соседи на мелких масштабах из Natural Earth, подробные
   данные OSM только по стране; масштабы 0–14, языки подписей `ru`, `tg`, `en`.
   **Отклонение:** полигоны морей (`water-polygons-split-3857`, ≈ 930 МБ) заменены пустым
   shapefile той же структуры (`empty_water_polygons.py`) — у Таджикистана моря нет, озёра и
   реки приходят из OSM и Natural Earth; для территорий у моря — `KCHS_BASEMAP_OCEAN=1`. Загрузки
   ≈ 620 МБ в кэш `seeds/.cache/basemaps` (вне git). На машине разработки (macOS, Docker,
   `-Xmx4g`) сборка заняла 6 минут, из них ≈ 4 минуты — загрузка источников и образа, обработка —
   меньше минуты; архив — 80 МБ, 61 574 тайла. Манифест `kchs-basemap/1`
   (`pmtiles_manifest.py`): ключ, версия (дата), файл, размер, SHA-256, масштабы, охват, центр,
   слои схемы, атрибуция. Шрифты — Noto Sans Regular/Bold/Italic из openmaptiles/fonts v2.0
   (PBF, 256 диапазонов на шрифт, кириллица с таджикскими буквами, ≈ 100 МБ); спрайты — свои
   (`sprites.py`: населённый пункт, столица, вершина; цвета тем из токенов, 1× и 2×).
2. **Хранилище** — бакет тайлов (`S3_BUCKET_TILES`), каталог `BASEMAPS_PREFIX` (по умолчанию
   `basemaps`, у интеграционных тестов свой): `vector/<ключ>/<версия>.pmtiles` и
   `manifest.json`, `glyphs/<шрифт>/<диапазон>.pbf`, `sprites/basemap-<тема>[@2x].{json,png}`,
   `raster/<id>/<метка адреса>/<z>/<x>/<y>` — кэш растрового прокси.
   `kchs basemaps upload <каталог>` проверяет архив (заголовок PMTiles v3, размер и SHA-256 из
   манифеста), загружает шрифты, спрайты, архив и последним — манифест (неизменённое по
   MD5/ETag пропускает), затем регистрирует подложку; `--no-register` — только файлы.
3. **Реестр.** Базовая карта — объект реестра типа `basemap`, создаётся через `ObjectService` в
   той же транзакции, глобальный: без пространства и владельца, ACL `everyone:view` — как
   территории (ADR-0057). Управление — действие `manage` типа со способностью
   `gis.basemaps.manage`: маршруты объявляют `auth: { action: 'manage' }` или
   `{ capability }`, проверок ролей в модуле нет. Сверх модели данных — `key` (уникальный:
   ключ сборки или `none`, по нему `sync` находит свою запись) и `secret_enc` (ключ растрового
   сервера шифром `KCHS_MASTER_KEY`). `url` у векторной — ключ архива в бакете, у растровой —
   шаблон XYZ без ключа; `style` — сведения сборки (версия, файл, размер, SHA-256, охват,
   центр, слои) или размер растрового тайла. Подложка по умолчанию одна (частичный уникальный
   индекс). События: `basemap.updated` (`changed`), `basemap.default_changed` (`previousId`)
   и `object.*` ядра.
4. **Синхронизация** `BasemapService.sync` — в `kchs init`, `kchs seed`,
   `kchs basemaps sync|upload`: «Без подложки» (`key = none`, только фон) есть всегда и не
   удаляется; сборки из манифестов регистрируются или переходят на новую версию (прошлый архив
   удаляется из хранилища); нет подложки по умолчанию — первая векторная, иначе «без подложки»;
   векторная сменяет «без подложки» в роли подложки по умолчанию. Хранилище недоступно —
   регистрируется только «без подложки». Удаление векторной удаляет из хранилища и её сборку
   (иначе `sync` вернул бы её); подложку по умолчанию удалить нельзя.
5. **Стиль** `GET /gis/basemaps/{id}/style.json?theme=light|dark|muted&lang=ru|tg|en` собирает
   API (спецификация MapLibre v8). Векторная — слои схемы OpenMapTiles (земля, вода, здания,
   дороги, границы, подписи) над источником
   `pmtiles://{KCHS_BASE_URL}/api/v1/gis/basemaps/{id}/pmtiles/{файл}`; растровая — источник
   `…/gis/basemaps/{id}/tiles/{z}/{x}/{y}?v=<метка адреса>`; «без подложки» — только фон.
   Шрифты — `…/gis/glyphs/{fontstack}/{range}.pbf`, спрайт — `…/gis/sprites/basemap-<тема>`.
   Адреса абсолютные от `KCHS_BASE_URL`: web и API — один источник за прокси (ADR-0044), cookie
   сессии уходит с запросами MapLibre. Цвета — токены дизайн-системы (фон — `bg-canvas`,
   подписи — `text-*`, гало — цвет фона), вода и здания — из `02-design-system.md` §4;
   unit-тест сверяет палитру и цвета спрайтов с `tokens.json` и прогоняет стили всех тем и
   языков через `validateStyleMin` из `@maplibre/maplibre-gl-style-spec`.
   `metadata['kchs:firstSymbolLayer']` — первый слой подписей: карта вставляет слои данных под
   него. Подписи — `name:<язык>`, затем русское и исходное название.
6. **Архив** отдаёт прокси API из MinIO: `GET …/pmtiles/{файл}` с `Range` — 206
   (`Content-Range`, `Accept-Ranges`), без `Range` — 200 потоком, недопустимый диапазон — 416;
   файл прошлой версии — 404 (адрес меняется с версией, ответ `immutable`). Каждый запрос
   проходит `authorize(view)`; лимит частоты — как у тайлов слоёв. Шрифты и спрайты — общие
   ресурсы, не объекты: любая сессия.
7. **Растровый прокси** `GET …/tiles/{z}/{x}/{y}`: шаблон с `{z}`, `{x}`, `{y}` и `{key}`;
   ключ подставляет сервер — клиенту и после сохранения администратору он не отдаётся, шаблон
   видят только управляющие подложками. Тайлы кэшируются в бакете, смена адреса очищает кэш.
   От SSRF: только http(s), без учётных данных в адресе и перенаправлений, ответ — изображение
   до 5 МБ за 10 с; loopback, link-local (метаданные облака), `0.0.0.0/8` и multicast закрыты —
   адрес проверяется после разрешения имени, в момент соединения; частные сети открыты (сервер
   тайлов закрытого контура). Атрибуцию MapLibre вставляет как HTML: ввод администратора
   экранируется, атрибуция сборки приводится к тексту.
8. **Клиент.** Консоль администрирования, раздел «Базовые карты» (способность
   `gis.basemaps.manage`): список, добавление и правка растровой XYZ, «по умолчанию»,
   удаление; предпросмотра нет. `features/gis/basemaps.ts` — `basemapsQuery`,
   `useBasemapStyle(basemapId, theme)` (null — подложка по умолчанию, язык — язык интерфейса)
   и `registerPmtilesProtocol(maplibre)` на пакете `pmtiles` — для MapView карты-студии.

## Альтернативы

- **Сборка с морскими полигонами** — +930 МБ загрузки без пользы для страны без моря;
  оставлена флагом.
- **Готовые архивы Protomaps** — схема Protomaps, а не OpenMapTiles (`18-tech-stack.md`), и
  выгрузку по стране всё равно пришлось бы делать.
- **Подписанные ссылки прямо в MinIO** — права не проходят `authorize`, подпись истекает
  посреди работы с картой, браузеру нужен опубликованный адрес MinIO с CORS.
- **Тайлы z/x/y из архива на сервере** (API сам читает каталоги PMTiles) — кэш браузера без
  протокола `pmtiles://`, но свой разбор архива; вернуться, если Range-прокси станет узким
  местом (для S2 — кэш nginx/CDN перед API).
- **Кэш растровых тайлов в Redis** — занимает память; хранилище дешевле и переживает перезапуск.
- **Реестр вне реестра объектов** (настройки установки) — нарушает правило №1; глобальный
  объект с `everyone:view` уже работает у территорий.

## Последствия

- Установка без интернета получает подложку одной загрузкой каталога сборки
  (`kchs basemaps upload`); собрать можно на другой машине. Процедура — `15-admin-operations.md`
  §6, источники и лицензии — `seeds/README.md`.
- Каждый диапазон архива проходит `authorize` (несколько запросов к БД); при нагрузке S2 —
  кэш решений или кэширующий прокси.
- Гостевая ссылка (ADR-0032) стиль подложки не получает: базовая карта — отдельный объект.
  Решается вместе с гостевым доступом к картам.
- Спутниковые снимки (COG через TiTiler) и WMS/WMTS — фаза 3; атрибуцию источника карта-студия
  показывает стандартным элементом MapLibre (условие ODbL и OpenMapTiles).
