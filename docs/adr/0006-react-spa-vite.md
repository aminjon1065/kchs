# 0006. React SPA на Vite с TanStack Router
Статус: Принято. Дата: 2026-09-17

## Контекст
Приложение целиком за аутентификацией, с тяжёлым клиентским состоянием (вкладки, панели, карты, гриды), без потребности в SEO.

## Решение
React 19 + Vite + TanStack Router/Query + Zustand; ленивые модули; печатные маршруты в том же приложении.

## Альтернативы
Next.js (SSR не нужен, усложняет состояние и WebGL); Vue/Svelte (меньше экосистема для карт/гридов/редакторов).

## Последствия
Быстрая сборка; простое развёртывание статики; необходимость собственного управления состоянием вкладок.
