# ADR-0102. Происхождение и влияние: граф зависимостей с правами смотрящего

Статус: **Принято** · Дата: 2026-09-20 · Фаза 5 (P5-E03)

## Контекст

Ядро уже ведёт вычисляемые зависимости `dependencies(from_id, to_id, kind)` —
их пересчитывают модули при сохранении объекта (дашборд → график → запрос →
датасет; слой → датасет; отчёт → график). `06-analytics-engine.md` §15 требует
показать на их основе происхождение и анализ влияния.

## Решение

1. **Обход графа в обе стороны** от объекта на заданную глубину (по умолчанию
   три шага, не больше пяти): «вверх» — что объект использует, «вниз» — кто
   использует его. Узлы помечаются глубиной со знаком, поэтому интерфейс
   раскладывает их на «откуда данные» и «где используется».
2. **Права — на каждом шаге обхода**: сосед попадает в граф, только если
   проходит предикат видимости ядра. Ребро в невидимый узел из ответа
   выбрасывается — иначе оно выдавало бы существование чужого объекта.
3. **Предел узлов** (60) и признак `truncated`: граф в контекстной панели
   должен читаться человеком, а не быть полной выгрузкой связей.
4. **Анализ влияния на уровне полей** (какие графики сломает удаление поля) в
   этот шаг не входит: он требует разбора спецификаций запросов и графиков.
   Сейчас влияние — это множество потребителей объекта, и его достаточно,
   чтобы предупредить перед изменением схемы.

## Последствия

- Один маршрут `GET /objects/{id}/lineage` обслуживает любой тип объекта: граф
  строится ядром, а не модулем данных, и работает для слоёв, отчётов и карт.
- Два разных пользователя видят разные графы одного объекта — это правильно и
  проверено тестом.
- Глубина обхода — несколько запросов к `dependencies` (по одному на шаг в
  каждую сторону); при типичной глубине 3 это дёшево.

## Альтернативы

- **Рекурсивный CTE** одним запросом — быстрее, но предикат видимости пришлось
  бы применять после обхода, и невидимые узлы утекали бы в промежуточные пути.
- **Хранить готовый граф** отдельной таблицей — лишняя синхронизация: сами
  зависимости уже поддерживаются модулями.
