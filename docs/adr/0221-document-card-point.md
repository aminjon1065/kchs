# 0221. Точка на карте в реквизитах документа; «Место на карте» в донесении

Статус: Принято
Дата: 2026-10-14

## Контекст

ADR-0212 («Чего нет и почему») оставил донесение без точки на карте: место — район и
населённый пункт, точку на карте обстановки ставит регистрирующий. Поле-точка с картой есть у
форм сбора (ADR-0157), но тип карточки документа геометрию не допускал
(`UNSUPPORTED_CARD_TYPES`). Печать и шаблоны выводили значение-объект как `[object Object]`.

## Решение

1. **Тип карточки** допускает поле `geometry` только с `geometryType: 'point'`. Линия, полигон и
   геометрия без вида — отказ `unsupported_type` (N160).
2. **Значение** — строго GeoJSON Point: долгота −180…180, широта −90…90, числа; лишние ключи
   отбрасываются; иное — 400 `invalid_point`. Пустое значение допустимо, если поле не
   обязательное.
3. **Текст точки** (`@kchs/fields`, `formatValue`): «широта, долгота» с пятью знаками — печать,
   шаблоны и выгрузки. Поиск по документу берёт из карточки только строки и числа, точка в
   индекс не попадает.
4. **Пакет ЧС**: у донесения (`situation_report`) поле **«Место на карте»** (`location`) после
   «Населённый пункт»; на установленном пакете его досоздаёт обновление пакета.
5. **Веб**: в карточке и в диалоге «Донесение» поле-точка ADR-0157 — «Указать место», карта,
   широта и долгота, «Моё местоположение». Без права правки рядом с координатами кнопка
   «Показать на карте»: карта с точкой только для просмотра.

## Чего нет и почему

- **Слой «Донесения» на карте «Обстановка ЧС».** Не сделан (N161): строки датасета видны по
  правам пространства, а документы — по своим правам и грифу. Слой из документов показал бы
  место и подпись конфиденциального донесения тем, кому документ не открыт. Следующий шаг —
  системный датасет документов с правами смотрящего.

## Альтернативы

- **Любая геометрия в реквизитах.** Отклонено: линия и полигон в карточке не нужны ни одному
  типу, а редактор формы для них тяжёлый.
- **Точка двумя числовыми полями.** Отклонено: нет карты, проверки границ и вида на печати.

## Последствия

- Миграции нет: карточка — JSON документа.
- Тесты: интеграционный `document-card-point.test.ts` (тип, нормализация, отказы),
  `emergency-pack.test.ts` (поле у донесения), unit `@kchs/fields` (текст точки), компоненты
  `point-field.test.tsx` (просмотр без права правки).
- e2e `documents-report-offline.spec.ts` — поле необязательное, сценарий прежний.
