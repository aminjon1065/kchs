# 0008. Собственный DataGrid на TanStack Table/Virtual
Статус: Принято. Дата: 2026-09-17

## Контекст
Таблица данных — центральный компонент аналитика; нужны виртуализация, редактирование, выделение, кастомные ячейки по типам и премиальный единый стиль.

## Решение
Собственный `DataGrid` в дизайн-системе на TanStack Table + TanStack Virtual (строки и столбцы), серверная пагинация/группировка через QuerySpec.

## Альтернативы
AG Grid Community (группировка/pivot только в платной Enterprise; стилизация ограничена); Glide Data Grid (canvas — трудно кастомизировать ячейки и доступность).

## Последствия
Инвестиция в компонент; обязательные ранние бенчмарки; запасной путь — AG Grid Community за интерфейсом `DataGridProps`, если бюджеты производительности не достигнуты к концу фазы 1.
