# 0007. Оболочка «рабочее пространство»
Статус: Принято. Дата: 2026-09-17

## Контекст
Пользователи работают с несколькими объектами одновременно (таблица + карта, документ + данные), должны сохранять контекст между днями и не теряться в большом приложении.

## Решение
Рейл модулей + навигатор + вкладки объектов с предпросмотром и разделением панелей + контекстная панель + палитра команд + строка состояния; «Мой день» как стартовая вкладка; сохранение состояния на сервере; связанные представления.

## Альтернативы
Страничная навигация (потеря контекста); оконный рабочий стол (хаос окон); дашборд-центричность (инструменты в глубине).

## Последствия
Единая модель открытия объектов; ограничения на тяжёлые компоненты в фоне; больше внимания состоянию вкладок и клавиатуре.
