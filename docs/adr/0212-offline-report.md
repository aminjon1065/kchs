# 0212. Донесение без сети: ключ идемпотентности создания документа, фото черновика, очередь устройства

Статус: Принято
Дата: 2026-10-13

## Контекст

ADR-0204 отложил донесение без сети. Очередь устройства умела одну отправку — сдачу сводки,
у которой был ключ идемпотентности. У создания документа его не было. Если ответ
`POST /documents` теряется, повтор из очереди создаёт второй черновик.

Донесение в kchs — документ типа «Донесение» (`situation_report`) из стартового набора.
Пакет ЧС добавляет ему реквизиты ЧС: вид, масштаб, район, время, пострадавшие, погибшие,
эвакуированные, ущерб, меры (`04-domain-pack-emergency.md`). Заводят донесение двумя путями.
Канцелярия и дежурная смена регистрируют его экраном регистрации, а общий «Создать» входящие
типы не предлагает. Быстрой формы для сотрудника в поле, где связь пропадает, не было.
Концепт-нота (§4.2) требует отложенной отправки и фото.

## Решение

1. **Ключ идемпотентности создания.** У `DocumentCreateInput` появился `clientKey` (uuid
   устройства), у `documents` — колонка `client_key` с уникальностью по автору и ключу.
   - Повтор с тем же ключом от того же автора возвращает уже созданный документ. Событие
     `document.created` и аудит пишутся один раз.
   - Гонку одновременных повторов снимает блокировка `pg_advisory_xact_lock` по автору и
     ключу. Уникальный индекс страхует от ошибки в коде.
   - Ключ, занятый документом другого типа, даёт 409.
   - Без ключа создание работает как раньше.
2. **Фото черновика** — `POST /documents/{id}/photos` `{clientKey, data}`.
   - Принимается JPEG до 3 МБ, не больше 30 снимков у документа.
   - Сервер выбрасывает метаданные: очистка `shared/jpeg.ts` общая с фото сводки
     (ADR-0208).
   - Снимок становится файлом реестра в пространстве документооборота, прикреплённым к
     документу (`attachment`). Видит его тот, кто видит документ.
   - Повтор с тем же ключом снимка возвращает тот же файл: учёт в `document_photos`.
   - Добавлять фото можно только в черновик. Дальше файлы идут версиями документа
     (ADR-0197): из прикреплённого снимка автор делает приложение версии.
3. **Диалог «Донесение»** на экране «Документы». В нём тема, реквизиты типа (те же
   контролы, что в карточке) и снимки, сжатые на устройстве как в ADR-0208. Ключ создания
   выдаётся при открытии диалога.
   - При связи документ создаётся сразу, снимки загружаются, черновик открывается во вкладке.
   - Без сети донесение ложится в очередь устройства как запись `document.create` и уходит
     само тем же ключом.
   - Отказ по существу при связи показывает сам диалог.
4. **Очередь** (ADR-0204) получила второй вид записи.
   - Досылка: создание с ключом, затем каждый снимок под своим ключом. Загруженный снимок
     помечается на устройстве, следующий проход его пропускает.
   - Отказ по существу оставляет запись «не отправлено» с причиной и «Убрать из очереди».
     Снимки стираются вместе с записью.
   - Уведомление «Донесение из очереди отправлено» показывает строка состояния, потому что
     диалог к этому времени закрыт.
   - Очередь ведётся по сотруднику: записи других людей на общем устройстве не досылаются.
5. **Справочники на устройстве.** Типы документов и территории запоминаются по сотруднику
   (`cachedFetch`) и запрашиваются в режиме `offlineFirst`. Без этого донесение без сети не
   заполнить: район в нём обязателен. Код экрана документов и диалога модуль документов
   объявляет для работы без сети (`offline`, ADR-0207).

## Чего нет и почему

- **Автоматическая доставка дежурной смене.** Донесение остаётся черновиком автора. Причина:
  тип «Донесение» входящий, и регистрация требует корреспондента и даты поступления (проверка
  реквизитов входящего). Маршрута «на регистрацию дежурной смене» в пакете нет. Как доставлять
  донесение из поля, решает владелец (N129); до ответа автор передаёт его, когда связь есть.
- **Точка на карте в донесении.** Поля-точки у реквизитов донесения нет: место — район и
  населённый пункт. Точку на карте обстановки ставит регистрирующий, как раньше.

## Альтернативы

- **Общий `Idempotency-Key` с таблицей ответов.** Отклонено, как в ADR-0204: у документа есть
  строка, к которой ключ привязывается естественно.
- **Снимки — приложениями версии сразу.** Отклонено: у версии обязателен основной файл, а
  донесение из поля — карточка и снимки. Версию с приложениями автор делает из черновика.
- **Отдельная форма сбора «Донесение».** Отклонено: донесение — документ с журналом, номером
  и правилами (поручения по регламенту), а сводка пишет строку датасета.
