# Дизайн-система

Статус: **Решено** для токенов и принципов; **Рекомендовано** для конкретных значений (исполнитель может калибровать, сохраняя структуру и контраст).

## 1. Принципы

1. **Спокойствие.** Нейтральные поверхности, один акцент, цвет — для смысла (статус, данные), а не для украшения.
2. **Плотность с воздухом.** Много информации на экране, но с чёткой иерархией: сетка 4px, выверенные интерлиньяжи, выравнивание чисел.
3. **Точность.** Табличные цифры, единицы, форматы дат, выравнивание по правому краю для чисел, моноширинный шрифт для кодов и координат.
4. **Согласованность.** Одинаковые компоненты и поведение во всех модулях; никаких «особых» экранов.
5. **Движение по делу.** Короткие переходы, объясняющие, откуда что появилось; ничего не «плавает».
6. **Обе темы — первоклассные.** Тёмная тема не инверсия, а отдельно выверенные поверхности.

### Цвет: данные

- **Категориальная палитра тегов** (`--chart-1…10`, порядок фиксирован): `#2F62E6` синий, `#E8842F` оранжевый, `#1C9A62` зелёный, `#D63B3B` красный, `#8B5CF6` фиолетовый, `#0EA5B7` бирюзовый, `#C9A227` горчичный, `#D9509C` розовый, `#5B7083` серо-синий, `#7C5C3B` коричневый. Тёмная тема — осветлённые варианты (+12 % L). Для графиков этот порядок не годится: зелёный рядом с красным при дейтеранопии неразличим (ADR-0049).
- **Палитра графиков** (`--viz-cat-1…8`, ADR-0049): те же оттенки в порядке синий, оранжевый, розовый, горчичный, бирюзовый, красный, фиолетовый, зелёный; в тёмной теме оранжевый `#C96B1E` и горчичный `#B28D09` — шаги темнее. Порядок и шаги проверяет `pnpm --filter @kchs/ui contrast`: соседние цвета при цветослепоте (протанопия, дейтеранопия) — ΔE OKLab ≥ 8, при обычном зрении — ≥ 15, первые три — все пары. Не больше 8 серий: остальные — в «Прочее» (`--viz-other`, серо-синий); у точечных — не больше 3 групп. Контраст части цветов на белом ниже 3:1 — поэтому у графика всегда легенда или подписи и «Таблица данных». Последовательная — `--viz-seq-1…6` (синяя, в тёмной теме от тёмного к светлому), расходящаяся — `--viz-div-1…7`.
- **Последовательные** шкалы (карты, тепловые, ADR-0065): `blue` (`#E9EFFF → #193CA0`), `teal`, `orange`, `viridis` (для плотности) — `--seq-<шкала>-1…7`, свои шаги в каждой теме: малое значение в светлой теме светлое, в тёмной — тёмное. Классы 3–9 компилятор `packages/map-style` интерполирует в OKLab.
- **Расходящиеся**: `red–blue` (нейтраль — surface-2 светлой и surface-3 тёмной темы, как `--viz-div`), `brown–teal` — `--div-<шкала>-1…7`. Шаги светлоты и различимость полюсов при цветослепоте проверяет `contrast`.
- **Статусы задач/документов**: черновик — muted, в работе — accent, на согласовании — фиолетовый `--purple`, выполнено — success, просрочено — danger, отменено — muted перечёркнуто.
- Правило: цвет данных никогда не совпадает с цветом интерфейсных состояний в одном контексте (кнопка «Удалить» не рядом с красной серией без подписи).

### Типографика

Шрифт: **Inter** (переменный, `font-feature-settings: 'tnum' 1, 'cv11' 1, 'ss01' 1`), моно: **JetBrains Mono**. Оба самостоятельно размещены (woff2, subset cyrillic+latin).

Реализация (P0-E13 S03): файлы в `packages/ui/src/fonts`, `@font-face` — `packages/ui/src/styles/fonts.css`; приложение и Storybook подключают один CSS, сборка выдаёт шрифты отдельными файлами того же origin (CSP `font-src 'self'`).

- Подмножества latin, cyrillic и cyrillic-ext с диапазонами Google Fonts: браузер скачивает файл, только если на странице есть его символы. cyrillic-ext несёт таджикские Ғғ Ӣӣ Ққ Ӯӯ Ҳҳ Ҷҷ.
- Inter 4.1 и JetBrains Mono 2.304 — релизы авторов (в сборках Google Fonts нет `cv11`/`ss01`); Inter закреплён на оптическом размере 14 с осью насыщенности 100–900, JetBrains Mono — 100–800.
- В JetBrains Mono нет Ӣӣ Ӯӯ Ҳҳ: их рисует Noto Sans Mono с той же шириной знака (0,6 em) — отдельное правило `@font-face` того же семейства, моноширинная сетка не ломается.
- Утилита `font-mono` задаёт свои функции OpenType (`--font-mono--font-feature-settings: "calt" 0`): `cv11`/`ss01` Inter не включают одноимённые варианты глифов JetBrains Mono, а лигатуры (`!=` → `≠`, `->`) выключены — коды и выражения видны знак в знак.
- Файлы собирает `packages/ui/scripts/build-fonts.py` из источников, закреплённых по версии и SHA-256. Лицензии — SIL Open Font License 1.1 (Inter, JetBrains Mono, Noto Sans Mono), тексты — `packages/ui/src/fonts/OFL-*.txt`.
- Визуальный тест `packages/ui/visual/fonts.spec.ts` по истории «Основы/Типографика» проверяет, что каждый знак нарисован собственными шрифтами, а не системными.

### Отступы, радиусы, тени

- Сетка 4px: `1=4, 1.5=6, 2=8, 3=12, 4=16, 5=20, 6=24, 8=32, 10=40, 12=48, 16=64`.
- Радиусы: `xs=4` (чипы, kbd), `sm=6` (контролы, кнопки), `md=8` (карточки, поповеры), `lg=12` (диалоги, плитки дашборда), `full`.
- Тени (светлая): `sm: 0 1px 2px rgba(16,17,20,.06)`, `md: 0 4px 12px rgba(16,17,20,.08), 0 1px 3px rgba(16,17,20,.06)`, `lg: 0 12px 32px rgba(16,17,20,.14), 0 2px 6px rgba(16,17,20,.08)`. Тёмная: тени слабее, иерархия через поверхности + 1px рамка `--border`.
- Рамки: 1px `--border`; фокус — `box-shadow: 0 0 0 2px var(--bg-surface), 0 0 0 4px var(--accent-ring)`.

### Движение

- Длительности: `fast=100ms` (hover, нажатие), `base=150ms` (появление меню/поповера), `slow=200ms` (панели, вкладки), `modal=250ms`.
- Кривые: стандартная `cubic-bezier(.2,0,0,1)`, выход `cubic-bezier(.4,0,1,1)`, подпружиненная только для drag-and-drop.
- Паттерны: поповеры — масштаб 0.96→1 + прозрачность от точки привязки; панели — сдвиг 8px + прозрачность; вкладки — перекрёстное затухание содержимого 120ms; списки — без анимации перестановки, кроме drag-and-drop; скелетоны — мягкая пульсация 1.6с; `prefers-reduced-motion` отключает всё, кроме прозрачности.

### Слои

`z-base=0, z-sticky=10, z-panel=20, z-dropdown=30, z-overlay=40, z-modal=50, z-toast=60, z-tooltip=70`.

### Иконки

Lucide, штрих 1.5px; 16px в контролах и таблицах, 20px на рейле, 24px в пустых состояниях. Глифы типов объектов — фиксированный набор (датасет, слой, карта, документ, задача, поручение, файл, папка, страница, встреча, событие, тетрадь, дашборд, показатель, отчёт, форма, территория, пространство) с цветом по типу (только в чипах и навигаторе). У каждого типа реестра свой глиф (`ObjectIcon`, тест на повторы); неизвестный тип — нейтральный глиф «объект».

## 4. Темы графиков и карт

- ECharts-тема из токенов (ADR-0049): фон прозрачный, сетка — сплошная 1px `--border`, линия оси — `--border-strong`, подписи `--text-secondary` 12px (текст никогда не цветом серии), тултип на `--bg-overlay` с рамкой и тенью `md` (разметка на классах, без встроенных стилей — CSP), палитра `--viz-*`, hover-подсветка серией, легенда снизу с чипами — только для двух и более серий. Столбцы ≤ 24px со скруглением 4px на конце, линии 2px, маркеры 8px с кольцом поверхности, зазор 2px между заливками. Числа и периоды — форматтеры платформы (`packages/fields`). Компилятор — `packages/chart-spec`, компоненты — `Chart`, `NumberTile`, `ChartTable` в `@kchs/ui`.
- Базовая карта: приглушённые оттенки (`light`: дороги `#E4E4E8`, вода `#D9E4F5`, здания `#ECECEF`; `dark` аналогично) — данные всегда контрастнее фона. Подписи слоёв — Inter с гало цвета поверхности. Легенда — компонент дизайн-системы, не встроенная в карту.
- Редактор кода (`SqlEditor`; та же тема — у будущего ExpressionInput): CodeMirror 6, грузится лениво отдельным чанком. Тема — CSS-переменные токенов, поэтому смена темы перекрашивает редактор без пересоздания; шрифт — `font-mono` (без лигатур), кегль `text-sm`. Подсветка: ключевые слова — `--accent`, строки — `--success`, числа и литералы — `--warning`, типы — `--purple`, комментарии — `--text-muted`, параметры `{{name}}` — `--purple` на `--purple-subtle`; имя в кавычках — обычный текст. Ошибка — волнистое подчёркивание `--danger` (`--warning`), подсказка с текстом — при наведении и у курсора, без мыши. Рамка и фокус — как у поля ввода: кольцо на рамке (`data-field`), не на области правки. Правила темы CodeMirror вставляет в `<style>` с nonce страницы (ADR-0043); `packages/ui/visual/sql-editor.spec.ts` проверяет редактор под строгим CSP. Клавиатура: `Tab` — отступ или выбор подсказки, `Escape`, затем `Tab` — выход из редактора, `⌘/Ctrl+Enter` — выполнить.

## 5. Состояния

- **Пустые**: иллюстрация-глиф + одна фраза + одно действие («Загрузите первый файл»).
- **Загрузка**: скелетоны, повторяющие форму контента (не спиннер), для таблиц — 8 строк; действия — спиннер в кнопке.
- **Ошибки**: inline-Callout с причиной и действием («Повторить», «Запросить доступ»); глобальные — toast danger; форма — под полем.
- **Нет доступа**: замок + «Нет доступа к данным» + «Запросить».
- **Офлайн/переподключение**: полоса состояния снизу, ввод не блокируется, отправка ставится в очередь.

## 6. Голос интерфейса (ru)

Короткие глаголы в кнопках («Сохранить», «Согласовать», «Создать поручение»), без восклицаний, без «пожалуйста», без ёрничества; названия объектов — как назвал пользователь; системные сообщения — прошедшее время («Документ зарегистрирован»); ошибки — что случилось и что сделать. Таджикская и английская локали — переводы с сохранением длины (кнопки не ломаются: `min-width` и перенос).

## 7. Реализация

`packages/ui`: `tokens/` (json → css/tailwind), `primitives/`, `components/`, `composites/`, `hooks/`, `icons/`; Storybook (`packages/ui/.storybook`, истории `*.stories.tsx` рядом с компонентами; переключатели темы, плотности и языка на панели инструментов; `pnpm storybook`); визуальные тесты — снимки каждой истории в светлой и тёмной теме и проверка axe (`packages/ui/visual`, `pnpm --filter @kchs/ui test:visual` в Linux-образе Playwright, как в CI; снимки обновляет `test:visual:update`); правило: экран не считается готовым без соответствия токенам (линт `no-arbitrary-values` в Tailwind, кроме одобренных исключений).
