# Паттерны взаимодействия

Статус: **Решено** для DataGrid, CollectionView, FilterBuilder, SchemaForm, ShareDialog, палитры и вкладок; **Рекомендовано** для остального.

## 1. DataGrid (таблица данных)

- Виртуализация строк и столбцов (TanStack Virtual), серверная пагинация по курсору с предзагрузкой следующей страницы, приблизительный счётчик с уточнением.
- Заголовок: сортировка (клик, shift-клик — множественная), фильтр столбца (поповер по типу поля), изменение ширины (drag, двойной клик — по содержимому), перетаскивание порядка, закрепление слева, скрытие; меню столбца: сводка, группировка, «показать на карте», «в фильтр».
- Ячейки: рендер по типу (число выровнено вправо с табличными цифрами; дата в локали; булево — галка; справочник — подпись; пользователь — аватар+имя; территория — чип с уровнем; геометрия — мини-глиф + координаты; файл — иконка+имя; ссылка; длинный текст — обрезка с тултипом), состояние ошибки валидации (красная рамка + подсказка).
- Редактирование: двойной клик/`Enter`/начало ввода; `Esc` отмена; `Tab` вправо; вставка из буфера (много ячеек), заполнение перетаскиванием (fill handle), отмена `⌘Z` (локальная очередь изменений, отправка батчем с оптимистичным обновлением и откатом при ошибке).
- Выделение: строки (чекбокс, shift/⌘), диапазоны ячеек, столбцы; панель действий над выделением (счётчик, «Экспорт», «Показать на карте», «Создать поручение», «Изменить поле», «Удалить»); сводки по выделению внизу (сумма/среднее/мин/макс/уникальные).
- Группировка (серверная): сворачиваемые группы с итогами; сводная таблица (pivot) — отдельный режим над результатом агрегации.
- Строка-детали: `Space` — предпросмотр карточки строки в контекст-панели; `Enter` — открыть карточку.
- Производительность: 60 fps при прокрутке 100 столбцов × 100 000 строк; рендер ячеек чистыми функциями; измерение ширин по выборке.
- Доступность: роль `grid`, навигация стрелками, объявление ячеек, видимый фокус.

## 2. CollectionView и сохранённые представления

Единый компонент для списков объектов любого типа: панель сверху (поиск, FilterBuilder-чипы, сортировка, группировка, режим отображения, «Столбцы», «Сохранить представление»), режимы: таблица (DataGrid облегчённый), список (карточки), доска (KanbanBoard по полю), календарь (по дате-полю), таймлайн (по началу/сроку), карта (по территории/геометрии), галерея (файлы). Представления — объекты (`view`): личные/общие, закрепляемые в навигаторе, с URL. Изменение фильтров в общем представлении — «Изменено · Сохранить/Сбросить».

## 3. FilterBuilder

Чипы фильтров («Срок: до 30.09», «Исполнитель: я, Каримов») + поповер добавления: выбор поля (поиск, группы по типу), оператор по типу (текст: содержит/равно/начинается/пусто; число: =, ≠, <, >, между; дата: сегодня/на этой неделе/последние N дней/между/относительно; справочник: любой из; территория: в пределах (с дочерними); пользователь: я/мои подчинённые/конкретные; булево), значение. Группы И/ИЛИ (вложенность 2 уровня, «Расширенный режим» показывает дерево). Тот же компонент — в датасетах (QuerySpec `filter`), списках объектов, политиках строк, правилах автоматизации (условия). Быстрые фильтры-пресеты по типу. Всё через клавиатуру.

## 4. SchemaForm

Рендер формы из схемы полей: компоновка в 1–2 колонки, группы/секции (свёртываемые), условная видимость и обязательность, зависимые справочники (район зависит от области), валидация zod с сообщениями под полем и сводкой вверху при отправке, автосохранение черновика (для карточек документов/задач), inline-режим (свойства объекта редактируются на месте: клик → контрол → `Enter`/`Esc`), «грязное» состояние и подтверждение ухода. Типы → контролы по `packages/fields`.

## 5. Пикеры

- **ObjectPicker**: поиск по индексу с фильтром по типам, недавние, создание нового «на лету», множественный выбор чипами, предпросмотр при наведении.
- **UserPicker**: люди/группы/подразделения/должности с аватарами и должностью, «я», «мой руководитель», подчинённые; по структуре — дерево.
- **TerritoryPicker**: дерево + поиск + мини-карта; выбор уровня; «с дочерними».
- **DatePicker**: клавиатурный ввод `дд.мм.гггг`, относительные («через 3 рабочих дня» — показывает дату), календарь с выходными/праздниками, время.
- **FieldPicker** (для запросов): поля датасета с типами и семантикой, связанные датасеты раскрываются.

## 6. Диалог «Поделиться»

Единый для всех объектов: поле добавления (UserPicker) + уровень + срок + сообщение; список текущих прав с источником (явно/наследуется/пространство/политика) и возможностью изменить/удалить явные; переключатель наследования; секция «Доступ по ссылке» (уровень, пароль, срок, счётчик); «Проверить доступ пользователя» (AccessExplainer); для дашбордов/карт — «Также предоставить доступ к данным: …» с чекбоксами. Копировать ссылку — всегда доступно.

## 7. Палитра команд

`⌘K` из любого места; ввод → 150мс дебаунс; результаты группами; стрелки/`Enter`/`⌘Enter` (в новой вкладке)/`Alt+Enter` (в разделении); префиксы; контекстные команды текущего объекта первыми («Согласовать документ», «Экспорт датасета»); команды с параметрами («Создать задачу: {название}»); недавние команды вверху; `Esc` закрывает и возвращает фокус.

## 8. Клавиатура (основные)

| Действие | Клавиши |
|---|---|
| Палитра команд | `⌘K` |
| Навигатор / Контекст / Нижняя панель | `⌘B` / `⌘.` / `⌘J` |
| Новая вкладка (палитра) / Закрыть / Восстановить | `⌘T` / `⌘W` / `⌘⇧T` |
| Переключение вкладок | `Ctrl+Tab`, `⌘1…9` |
| Разделить панель | `⌘\` |
| Сохранить | `⌘S` |
| Создать (контекстно) | `C` |
| Поиск в текущем представлении | `/` |
| Перемещение в списках | `J`/`K`, `↑`/`↓` |
| Открыть / в новой вкладке | `Enter` / `⌘Enter` |
| Переход: Мой день / Входящие / Данные / Карты / Документы / Задачи / Чаты | `G H` / `G I` / `G D` / `G M` / `G O` / `G T` / `G C` |
| Согласовать / Отклонить (Входящие) | `A` / `R` |
| Шпаргалка | `?` |

Все сочетания — в `packages/ui/shortcuts` с настройкой пользователем и учётом раскладки (кириллица не мешает: сравнение по `code`).

## 9. Уведомления, подтверждения, отмена

- Toast справа снизу, 5 с, с действием; не более 3 одновременно; ошибки не исчезают до закрытия.
- Разрушительные действия: AlertDialog с описанием последствий; для удаления с зависимостями — список «что затронет».
- **Отмена вместо подтверждения** там, где возможно: удаление в корзину, изменение статуса, закрытие вкладки — toast «Отменить» 8 с.
- Длительные операции — прогресс в строке состояния и в «Процессах», уведомление по завершении.

## 10. Перетаскивание

Файлы в любую область объекта (вложение), вкладки в панели (разделение), объекты между разделами навигатора (перенос), плитки дашборда, карточки на доске, слои в дереве, строки в чат (чип), ячейки (fill). Индикаторы: подсветка зоны, «призрак» с названием, `Esc` отмена. Библиотека: `@dnd-kit`.

## 11. Обсуждение и упоминания

Композер: `@` — пользователи/группы, `#` — объекты (ObjectPicker inline), `:` — эмодзи, `/` — команды; `Enter` отправить, `Shift+Enter` перенос (настройка); прикрепление drag-and-drop/буфер обмена; цитата по выделению; редактирование стрелкой вверх; реакции по наведению; тред — «Ответить в треде».

## 12. Hover-карточки и чипы

Чип объекта: иконка типа + название (+ статус-точка); наведение 400мс — карточка (тип, пространство, владелец, 2–4 поля, действия). Чип пользователя — аватар, должность, подразделение, статус, «Написать», «Позвонить». Чип территории — уровень, родитель, мини-карта.

## 13. Мобильные адаптации

Список + карточка как стек с «Назад»; действия — в нижней шторке (Drawer); таблицы — карточный режим с 3–4 ключевыми полями и раскрытием; карта — полноэкранная с плавающими кнопками; формы — одна колонка, крупные контролы (44px); Входящие — свайпы (вправо согласовать/принять, влево отложить) с подтверждением.

## 14. Производительность восприятия

Оптимистичные обновления для статусов/полей/сообщений; предзагрузка при наведении (prefetch); мгновенное открытие вкладки со скелетоном; сохранение прокрутки; отсутствие layout-скачков (зарезервированные размеры); «свежесть» — тихая индикация («обновлено только что») вместо перезагрузки.
