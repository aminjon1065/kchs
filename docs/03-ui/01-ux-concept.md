# Концепция интерфейса: рабочее пространство

Статус: **Решено** (ADR-0006, ADR-0007).

## 1. Выбор концепции

| Концепция | Сильные стороны | Слабые стороны | Вывод |
|---|---|---|---|
| Страницы с навигацией (классическое веб-приложение) | привычно, просто | потеря контекста при переходах; невозможно держать таблицу и карту рядом | недостаточно |
| Рабочий стол с окнами | несколько объектов одновременно | управление окнами утомляет; перекрытия; плохо на ноутбуках; неочевидно, где что | отклонено |
| Дашборд-центричный | быстрый старт дня | инструменты «в глубине», аналитик и ГИС-специалист живут не в дашборде | как часть, не как основа |
| **Рабочее пространство: вкладки + разделяемые панели + контекстная панель + палитра команд** | несколько объектов без хаоса; контекст сохраняется; мощные инструменты рядом, но не на виду; знакомо по браузерам/IDE/PostHog | требует дисциплины в поведении вкладок и производительности | **выбрано**, с «Мой день» как стартовой вкладкой |

Дух ориентира (PostHog): единая оболочка для разных продуктовых областей, тетради как холст исследования, палитра команд, боковая панель с контекстом. Мы добавляем: полноценные вкладки объектов с разделением экрана, связанные представления (таблица↔график↔карта), Входящие как двигатель дня.

## 2. Анатомия оболочки

```
┌────┬───────────────┬──────────────────────────────────────────────────┬───────────────┐
│    │  Навигатор    │  ◀ Вкладки:  Мой день │ Уровни воды ✎ │ Карта паводка │ Док №12  ▶ │  Контекст     │
│ Р  │  (260px,      ├──────────────────────────────────────────────────┤  (320px,      │
│ е  │  сворачив.)   │  Панель А (таблица)          │ Панель Б (карта)  │  сворачив.)   │
│ й  │               │  ─ тулбар объекта ──────────  │ ─ тулбар ───────  │  Инфо │ Связи │
│ л  │  Пространства │                              │                   │  Обсуждение   │
│    │  Разделы      │                              │                   │  Активность   │
│ 56 │  Избранное    │                              │                   │  Ассистент    │
│ px │  Недавние     │                              │                   │               │
│    │               ├──────────────────────────────┴───────────────────┤               │
│    │               │  Нижняя панель (опц.): атрибуты слоя / SQL / задания              │               │
└────┴───────────────┴──────────────────────────────────────────────────┴───────────────┘
```

- **Рейл** (56px): логотип → «Мой день»; модули: Данные, Карты, Документы, Файлы, Задачи, Чаты, Встречи, Календарь, Знания; внизу: Поиск (`⌘K`), Входящие (счётчик), Уведомления, Ассистент, Настройки/Профиль. Активный модуль подсвечен; наведение — подпись.
- **Навигатор** (260px, `⌘B` скрыть): содержимое зависит от модуля — дерево пространств/разделов/объектов модуля, сохранённые представления, избранное, недавние; поиск в навигаторе; кнопка «Создать». В пространстве показывается всё пространство целиком (все типы), в модуле — только объекты модуля из всех пространств.
- **Вкладки**: каждая — объект или экран (список, представление, настройки). Вкладка «Мой день» закреплена первой. Поведение — раздел 4.
- **Панели**: вкладка занимает всю область или разделена на 2–4 панели (горизонтально/вертикально, вложенно). Каждая панель — объект с собственным тулбаром. Панели одной группы могут быть **связаны** (ViewContext).
- **Контекстная панель** (320px, `⌘.`): вкладки Инфо (свойства объекта, права), Связи, Обсуждение, Активность, Ассистент; относится к **сфокусированной** панели. Отдельные модули добавляют свои разделы (Карта: Объект/Анализ/Стиль; Документ: Маршрут/Действия шага).
- **Нижняя панель** (опц., `⌘J`): для аналитических/ГИС экранов — атрибутивная таблица, SQL-консоль, результаты запроса, задания.
- **Строка состояния** (внизу, тонкая): соединение realtime, фоновые задания (прогресс), замещение («Вы замещаете …»), горячие клавиши (`?`).

Ширины и наличие панелей запоминаются на пользователя и на тип экрана.

## 3. Навигация и адресация

- Универсальный адрес объекта `/o/{id}` (сервер редиректит по типу на `/data/datasets/{id}` и т. п.). Ссылки в тексте, чатах, уведомлениях, Telegram ведут во вкладку.
- Внутри объекта — вкладки объекта (например, у датасета: Таблица / Схема / Карта / Версии / Качество / Доступ) отражаются в URL (`?tab=schema`), состояние (фильтры, вид карты) — в `#`-части.
- Хлебные крошки в тулбаре панели: Пространство › Раздел › Объект; клик — переход в навигаторе, не новая вкладка.
- «Хабы»: паспорт территории, обзор проекта, карточка документа, обзор пространства — экраны, собирающие связанное вокруг объекта; из них навигация «по связям».

## 4. Поведение вкладок

1. Одинарный клик по объекту в списке/навигаторе открывает его в **предварительной** вкладке (курсивное название); следующий одинарный клик заменяет содержимое той же предварительной вкладки. Двойной клик, редактирование или закрепление делают вкладку постоянной. (Отключаемо в настройках: «Открывать всегда в новой вкладке».)
2. `⌘/Ctrl+клик` или средняя кнопка — новая вкладка в фоне; `Alt+клик` — открыть в разделении рядом; перетаскивание вкладки в область панели — разделение.
3. Объект не открывается дважды: повторное открытие переключает на существующую вкладку (кроме явного «открыть копию» для сравнения).
4. Вкладки можно закреплять, группировать по цвету, «закрыть остальные/справа», восстанавливать закрытые (`⌘⇧T`), переключать `⌘1..9`, `Ctrl+Tab`.
5. Несохранённые изменения — точка на вкладке; закрытие — подтверждение.
6. Состояние вкладки (скролл, фильтры, выделение, черновики) сохраняется при переключении и переживает перезагрузку (сервер + localStorage).
7. Лимит живых WebGL/тяжёлых компонентов в скрытых вкладках — 3; остальные восстанавливаются из состояния при активации.
8. Именованные **рабочие пространства** (наборы вкладок и разделений) сохраняются, открываются одним действием, могут быть общими.

## 5. Начало дня и переключение задач

- Вход → «Мой день» (Входящие, Сегодня, Задачи, Продолжить). Кнопка «Продолжить» восстанавливает вчерашний набор вкладок.
- Действия из Входящих выполняются без ухода: согласовать, принять, ознакомиться — в карточке элемента; «Открыть» — во вкладке.
- Переключение: вкладки, `⌘K` (последние объекты вверху), Недавние в навигаторе, ссылки-чипы.
- Уведомление realtime не крадёт фокус: toast с действием «Открыть», счётчики на рейле.

## 6. Работа с несколькими объектами

- Разделение экрана: таблица + карта, документ + данные, чат + дашборд. Связывание панелей одной кнопкой (цветная метка) — общий фильтр/выделение/время/экстент.
- Перетаскивание между панелями: строку датасета — в чат (ссылка-чип), файл — в документ (вложение), объект карты — в задачу (связь), график — в тетрадь.
- Всплывающие карточки (hover card) для чипов объектов: название, тип, статус, владелец, 2–3 ключевых поля, кнопки «Открыть», «В разделении».
- Отдельное окно браузера с той же сессией — синхронизировано (BroadcastChannel) для второго монитора (например, карта на большом экране).

## 7. Мощные инструменты без перегрузки

- **Прогрессивное раскрытие**: тулбар панели — 3–6 главных действий, остальное в «⋯»; секции «Дополнительно» в формах свёрнуты; режимы эксперта (SQL, выражения, JSON стиля) — явный переключатель.
- **Контекст вместо меню**: действия зависят от выделения (строки → «Создать поручение по 3 объектам», «Показать на карте»).
- **Умные значения по умолчанию** по роли и семантике данных (правильный тип графика, стиль слоя по типу поля, территория пользователя в фильтрах).
- **Клавиатура**: везде; палитра команд; `?` — шпаргалка.
- **Плотность**: комфортная/компактная; таблицы по умолчанию плотнее списков.
- **Единый язык паттернов**: один `CollectionView`, один `FilterBuilder`, одна форма, один диалог шаринга, одна карточка объекта — выучив один модуль, пользователь знает все.

## 8. Персонализация

Тема (светлая/тёмная/системная), акцентный цвет (в пределах палитры), плотность, размер шрифта (S/M/L), стартовый экран, набор виджетов «Мой день», закрепления в навигаторе, порядок модулей на рейле (скрытие неиспользуемых), язык (ru/tg/en), формат дат/чисел, тихие часы, поведение вкладок. Пресеты по роли при первом входе.

## 9. Адаптивность

- ≥ 1440: полная оболочка; 1280–1440: контекст-панель по умолчанию свёрнута; 1024–1280: навигатор и контекст как выдвижные оверлеи; ≤ 768 (мобильный веб): одна панель, нижняя навигация (Мой день, Входящие, Поиск, Чаты, Ещё), карточки и формы вертикально, карта на весь экран, вкладки — как «недавние».
- Мобильные приоритеты: Входящие с действиями, задачи, чаты, встречи, чтение документов/страниц, простые формы, карта-просмотр.

## 10. Доступность и локализация

WCAG 2.2 AA: контраст, фокус, клавиатура, ARIA через Radix, скринридер для таблиц (виртуализированные — с корректными ролями), уменьшенное движение, масштабирование до 200 %. Локали ru/tg/en с ICU-склонениями, форматирование Intl, RTL не требуется.
