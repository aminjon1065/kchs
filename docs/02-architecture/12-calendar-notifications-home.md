# Календарь, уведомления, Входящие и «Мой день»

Статус: **Решено** — Входящие как отдельный механизм и «Мой день» как стартовый экран; **Рекомендовано** — детали календаря.

## 1. Календарь

- Календари: личный (авто), командный/подразделения (авто для `unit`-пространств), проектный, ресурсный (переговорные, техника), подписки (ICS).
- События: заголовок, время/весь день, повтор (RRULE + исключения), место/комната, участники с ответами (да/нет/возможно/предложить время), напоминания (в приложении/почта/Telegram), видимость (открыто/занято/личное), связанные объекты, встреча (LiveKit) одной кнопкой, цвет.
- **Проекции**: сроки задач/поручений, сроки документов на контроле, дедлайны форм сбора, дежурства (предметный пакет) показываются как виртуальные события (не хранятся), с переходом к объекту.
- Виды: день/неделя/месяц/повестка/таймлайн команды; поиск свободного времени по участникам и ресурсам; перетаскивание; быстрое создание из палитры (`Встреча завтра в 10 с Ивановым`).
- Интеграции: ICS-экспорт/подписка (с токеном), импорт ICS; CalDAV/Google/Microsoft — фаза 5 (Открыто).
- Рабочее время и отпуска пользователя (из HR или вручную) — учитываются в подборе времени и делегировании.

## 2. Уведомления

Категории (для настроек): `inbox.*` (действия), `tasks.*`, `documents.*`, `chat.*`, `meetings.*`, `calendar.*`, `data.*` (импорт завершён, алерт, качество), `system.*`. Каналы: приложение (центр + toast + счётчик на рейле), e-mail (мгновенно/дайджест утром), Telegram (мгновенно), push (PWA). Правила по умолчанию: действия и упоминания — везде; изменения объектов, на которые подписан, — только в приложении; дайджест утром 08:00 по локальному времени. Тихие часы, «не беспокоить», режим «на встрече». Агрегация: несколько событий одного объекта за 5 минут — одно уведомление «3 изменения в Документ №…». Центр уведомлений: непрочитанные/все, группировка по объектам, «отметить всё», переход к объекту в новой вкладке.

## 3. Входящие

Элементы с состоянием (`inbox_items`): согласовать, подписать, наложить резолюцию, ознакомиться, принять поручение, отчитаться, принять результат, ответить на приглашение, проверить протокол, сдать форму, рассмотреть запрос доступа, разобрать алерт, обработать ошибку импорта. Каждый элемент — карточка с контекстом (кто, что, срок, ссылка) и **действиями прямо в списке** (согласовать/отклонить с комментарием, принять, ознакомиться, ответить), группировка по типу/сроку, фильтры «мои/замещаемые», отложить до времени. Закрытие автоматическое по событию действия; ручное закрытие невозможно (кроме «отклонить» там, где это действие). Счётчик Входящих — главный индикатор на рейле.

## 4. «Мой день»

Стартовая вкладка (закреплена первой, `G H`). Настраиваемая сетка виджетов (как дашборд, с системными плитками):

| Виджет | Содержание |
|---|---|
| Входящие | топ элементов по срочности с действиями, ссылка на все |
| Сегодня | таймлайн встреч и событий с кнопкой «Присоединиться», сроки задач |
| Мои задачи и поручения | сгруппированы: просрочено / сегодня / на неделе; быстрая отметка |
| Выданные мной | поручения на контроле по статусам (для руководителей) |
| Продолжить | вчерашние вкладки/рабочие пространства и недавние объекты |
| Закреплённое | избранные объекты и представления |
| Команда | нагрузка/просрочки отдела (руководителям), кто в отпуске/делегирует |
| Показатели | 2–4 показателя по выбору (например, «Происшествия за сутки») |
| Объявления | системные объявления и новые страницы для ознакомления |
| Активность | лента по подписанным объектам |

Роль определяет набор по умолчанию (руководитель: Входящие, Выданные, Показатели, Сегодня; аналитик: Продолжить, Данные (свежесть/качество), Закреплённое; делопроизводитель: Входящие, Журнал сегодня, Контроль). Пользователь настраивает. Мобильный вариант — одна колонка: Входящие → Сегодня → Задачи.

## 5. Восстановление контекста

Состояние рабочего пространства (вкладки, разделения, активные панели, состояние вкладок) сохраняется на сервере (`workspace_state` в `settings` пользователя) с дебаунсом; при входе предлагается «Продолжить» или «Начать с чистого». Именованные рабочие пространства («Паводок-2026»: карта + дашборд + чат штаба) — сохраняются и открываются одним действием, могут быть общими (объект `view` вида `workspace`).
