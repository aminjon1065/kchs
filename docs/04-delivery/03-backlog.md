# Бэклог: эпики и истории с критериями приёмки

Формат: `Pn-Exx` — эпик, ниже истории с критериями приёмки (КП). Истории сформулированы так, чтобы их можно было брать по одной и завершать с DoD (`02-roadmap.md`). Размер: S (до дня работы), M (1–3 дня), L (неделя), XL (разбить перед началом). Оценки относительны и служат для порядка, не для сроков.

---

## Фаза 0 — Ядро платформы

### P0-E01 Репозиторий, инфраструктура, CI
- **S01 Монорепо** (M): pnpm workspaces, turbo, biome, tsconfig-пресеты, dependency-cruiser с правилами границ, knip. КП: `pnpm lint typecheck test` проходят на пустых пакетах; нарушение границы падает в CI.
- **S02 Compose-инфраструктура** (M): postgres/postgis+pgvector, redis, minio (+init бакетов), meilisearch, caddy, профили `observability`, `dev`. КП: `docker compose up -d` поднимает всё; healthchecks зелёные; `.env.example` полный; скрипт генерации секретов.
- **S03 Каркас api** (M): Fastify, конфиг zod, pino, OpenTelemetry, problem+json, graceful shutdown, ROLE. КП: `/health`, `/api/openapi.json`; ошибка валидации → 400 problem+json.
- **S04 Каркас web** (M): Vite, TanStack Router/Query, i18n, тема, api-клиент из OpenAPI. КП: пустая оболочка с входом; typed client компилируется из OpenAPI.
- **S05 Каркас engine** (S): FastAPI `/health`, BullMQ-воркер «echo», Dockerfile с GDAL/LibreOffice/tesseract/ffmpeg. КП: задание из api исполняется engine и возвращает результат.
- **S06 CI** (M): матрица lint/typecheck/unit/integration(testcontainers)/build/e2e-smoke/trivy. КП: PR получает статус за ≤ 15 мин.

### P0-E02 База данных и миграции
- **S01 Drizzle-схема ядра** (L): таблицы из `05-data-model.md` (ядро + identity), роли БД, расширения. КП: миграции с нуля; тест «повторный запуск идемпотентен»; роль `kchs_query` не имеет прав на `public`.
- **S02 Seed-каркас** (S): команда `db:seed` с фабриками (пользователи, структура, пространства). КП: демо-организация из 3 уровней подразделений и 40 пользователей.

### P0-E03 Идентификация
- **S01 Регистрация администратора и вход** (M): argon2, сессии, cookie, CSRF, rate limit, блокировка. КП: неверный пароль ×10 → блокировка 15 мин; аудит `user.login/login_failed`.
- **S02 MFA TOTP и коды восстановления** (M). КП: включение с QR, проверка, коды одноразовые; принудительная MFA по политике роли.
- **S03 Восстановление доступа** (S): ссылка на почту 15 мин. КП: истёкшая ссылка отклоняется; сессии по выбору завершаются.
- **S04 Сессии и устройства** (S): список, завершение, «выйти везде». КП: завершённая сессия получает 401 немедленно.
- **S05 Профиль** (S): имя, аватар, локаль, часовой пояс, пароль. КП: смена пароля завершает другие сессии по выбору.

### P0-E04 Организация, роли, делегирование
- **S01 Оргструктура** (M): подразделения-дерево, должности, назначения, руководители, замыкание. КП: `manager(user)`, `subordinates(user)` корректны на тестовом дереве 4 уровней; перенос подразделения пересчитывает замыкание.
- **S02 Группы и роли** (M): группы, роли/способности, назначение. КП: способность проверяется в `authorize`; системные роли неудаляемы.
- **S03 Делегирование** (M): создание/завершение, PrincipalSet, баннер, «от имени» в аудите. КП: заместитель видит Входящие делегирующего в области scope; действия помечены `onBehalfOf`.
- **S04 Администрирование пользователей** (M): CRUD, блокировка, импорт из Excel, сброс MFA. КП: импорт 500 пользователей с отчётом об ошибках.

### P0-E05 Пространства и реестр объектов
- **S01 Objects + ObjectService + реестр типов** (L). КП: создание объекта любого зарегистрированного типа в транзакции с событием; `object_ancestors` корректны при переносе; корзина/восстановление/архив.
- **S02 Пространства** (M): типы, участники, роли, настройки, разделы. КП: личное пространство создаётся при создании пользователя; `unit`-пространства — при создании подразделения (опция).
- **S03 Универсальные эндпоинты** (M): `/objects/{id}`, `batch-get`, недавние, избранное, теги. КП: сводки объектов из реестра типов; недавние ограничены 200.

### P0-E06 Доступ
- **S01 ACL и authorize** (L): уровни, записи, наследование, роли пространств, `access_mode`, кэш PrincipalSet. КП: таблица истинности из `03-access-model.md` покрыта тестами; 404 без `view`.
- **S02 Политики типов** (M): интерфейс `TypePolicy`, предикат видимости для списков. КП: список объектов пространства фильтруется на SQL-уровне; тест на 10 тыс. объектов ≤ 100 мс.
- **S03 Диалог «Поделиться» и «Объяснить доступ»** (M). КП: показывает источник каждого права; проверка пользователя выдаёт reasons.
- **S04 Гостевые ссылки** (S). КП: ссылка с паролем/сроком; аудит открытий; отключение политикой.

### P0-E07 События, задания, realtime
- **S01 Outbox и шина** (M): запись в транзакции, диспетчер, Redis Streams, consumer groups, DLQ. КП: убийство worker во время обработки не теряет событие; дубликаты идемпотентны.
- **S02 Активность и аудит** (M). КП: лента объекта по событиям; `audit_log` только INSERT (тест роли).
- **S03 Задания** (M): BullMQ-очереди, реестр `jobs`, прогресс, отмена, экран «Процессы». КП: прогресс виден в UI через realtime; повтор после сбоя.
- **S04 Realtime-шлюз** (M): Socket.IO, комнаты, авторизация подписки, presence, Redis-адаптер. КП: `object.updated` приходит ≤ 500 мс; пользователь без прав не получает событий комнаты; отзыв прав исключает из комнаты.

### P0-E08 Обсуждения
- **S01 Беседы и сообщения** (L): беседа объекта, сообщения (Tiptap JSON), упоминания, реакции, вложения, треды, редактирование/удаление. КП: упоминание → уведомление; ссылка на объект → связь `mention`; права `comment`.
- **S02 Компонент обсуждения в контекст-панели** (M). КП: виртуализация, отметки прочтения, системные сообщения.

### P0-E09 Уведомления и Входящие
- **S01 Конвейер уведомлений** (M): правила категорий, агрегация, каналы приложение/e-mail, предпочтения, тихие часы. КП: 5 правок за 5 минут → одно уведомление; e-mail-дайджест по расписанию.
- **S02 Входящие** (M): модель, экран с действиями, авто-закрытие по событиям, отложить. КП: элемент закрывается при выполнении действия из любого места (UI/API).
- **S03 Центр уведомлений и счётчики** (S). КП: счётчики на рейле обновляются realtime.

### P0-E10 Поиск
- **S01 Индексация** (M): SearchDocument, aclPrincipals, дебаунс, переиндексация. КП: объект появляется в поиске ≤ 5 с; недоступный не появляется.
- **S02 Палитра команд** (M): объекты, команды, навигация, недавние, префиксы. КП: клавиатура целиком; открытие в новой вкладке/разделении.
- **S03 Страница поиска** (S): фасеты, сниппеты. КП: фильтры по типу/пространству/дате.

### P0-E11 Файлы
- **S01 Загрузка в S3 и версии** (L): сессии загрузки, multipart, докачка, версии, скачивание по подписанным URL, корзина. КП: файл 2 ГБ загружается с докачкой; версия восстанавливается.
- **S02 Папки и файловый менеджер** (M): дерево, CollectionView, drag-and-drop, массовые операции, наследование прав. КП: перенос папки сохраняет права по правилам.
- **S03 Превью и текст** (M): изображения, PDF (страницы), извлечение текста, индексация. КП: поиск по содержимому PDF.
- **S04 Вложения** (S): универсальное прикрепление к объектам, FileDropzone. КП: файл видно в панели «Связи» объекта.

### P0-E12 Поля, формы, коллекции
- **S01 `packages/fields`** (M): типы, валидация, форматирование, фильтры. КП: тесты форматов ru/tg/en; фильтр → SQL-предикат для объектов.
- **S02 SchemaForm** (M). КП: условная видимость, зависимые справочники, inline-режим, автосохранение.
- **S03 FilterBuilder + CollectionView + представления** (L). КП: сохранённое представление с URL; режимы таблица/список/доска; 60 fps на 10 тыс. строк.

### P0-E13 Дизайн-система
- **S01 Токены и темы** (M). КП: CSS-переменные из json; светлая/тёмная/плотность; контраст AA проверен скриптом.
- **S02 Базовые компоненты** (XL → разбить по группам): формы, оверлеи, навигация, обратная связь, данные (Skeleton, EmptyState, StatTile), Tree, VirtualList, Command. КП: Storybook со всеми состояниями; визуальные снимки в обеих темах; axe без ошибок.
- **S03 Шрифты и иконки** (S). КП: Inter/JetBrains Mono самостоятельно, subset; глифы типов.

### P0-E14 Оболочка рабочего пространства
- **S01 Рейл, навигатор, строка состояния** (M). КП: сворачивание с запоминанием; счётчики.
- **S02 Вкладки** (L): предпросмотр, закрепление, группы, dedupe, восстановление закрытых, `⌘1..9`, сохранение состояния (сервер+local), лимит тяжёлых компонентов. КП: перезагрузка восстанавливает 10 вкладок с состоянием; предпросмотр заменяется по правилам.
- **S03 Разделение панелей и ViewContext** (M). КП: drag вкладки в разделение; связь панелей с общим фильтром (демо на списке файлов).
- **S04 Контекст-панель** (M): Инфо/Связи/Обсуждение/Активность (+ заглушка Ассистент). КП: следует за фокусом панели.
- **S05 Горячие клавиши и шпаргалка** (S). КП: таблица из `03-ui/04-interaction-patterns.md`; работает с кириллической раскладкой.
- **S06 Именованные рабочие пространства** (S). КП: сохранение/открытие набора вкладок.

## Фаза 1 — Данные и аналитика

### P1-E02 Импорт
- **S01 Анализ файла (engine, sync)** (M): CSV/XLSX/JSON/GeoJSON, типы, локали, гео. КП: 20 тестовых файлов с «грязными» форматами распознаются.
- **S02 Мастер импорта (UI)** (L). КП: 4 шага; сохранение шаблона импорта.
- **S03 Выполнение импорта (engine, job)** (L): staging, COPY, валидация, режимы, отчёт ошибок, версия, события. КП: 5 млн строк ≤ 5 мин на S1; ошибки по строкам в файле.

### P1-E03 DataGrid и экран датасета
- **S01 DataGrid** (XL → виртуализация, столбцы, ячейки; редактирование; выделение и действия; группировка). КП: 100 столбцов × 100 тыс. строк 60 fps; вставка из буфера; undo.
- **S02 Экран датасета** (L): вкладки, профили столбцов, схема, версии, доступ, связи. КП: профиль столбца за ≤ 2 с на 5 млн строк (выборка).
- **S03 Карточка строки** (M). КП: связанные строки, обсуждение, связи.
- **S04 Экспорт** (M): CSV/XLSX/JSON/GeoJSON с политиками. КП: экспорт 1 млн строк как задание с файлом.

### P1-E04 Компилятор запросов
- **S01 Парсер выражений и типизация** (L). КП: 200 тестовых выражений; ошибки с позицией.
- **S02 Компилятор QuerySpec → SQL** (XL): все шаги v1 кроме spatial. КП: golden-тесты SQL; политики строк/столбцов применяются во всех источниках; тайм-ауты и лимиты.
- **S03 Кэш результатов** (S). КП: инвалидация по версии.
- **S04 Сырой SQL** (M): libpg-query, белый список, переписывание, роль. КП: 30 «атакующих» запросов отклонены; `pg_sleep` невозможен.
- **S05 Системные датасеты** (M): задачи (и заглушки документов/встреч). КП: запросы к системным датасетам с правами.

### P1-E05 Исследование и SQL-лаборатория
- **S01 Экран Explore** (L). КП: шаги, авто-выполнение, переключение визуализации, сохранение как график/датасет.
- **S02 SqlEditor** (M): автодополнение, параметры, история. КП: «человеческие» имена таблиц работают.

### P1-E06 Показатели, графики, дашборды

- **S02 Показатели** (M): каталог, вычисление, сравнения, цели/пороги, где используется. КП: одно значение везде (тест).
- **S03 Дашборды** (XL): сетка, плитки, фильтры, перекрёстная фильтрация, детализация, публикация, TV-режим, снимки PNG и подписки. КП: батч-запрос плиток; плитка без прав показывает «нет доступа».
- **S04 ChartBuilder** (M). КП: умные значения по умолчанию по семантике.

### P1-E07 Связи, справочники, территории (без карты)
