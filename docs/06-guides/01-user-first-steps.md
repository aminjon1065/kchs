# Первый вход и рабочее пространство

## Зачем это

kchs — не набор отдельных страниц, а одно рабочее пространство: вкладки,
разделённые панели, контекстная панель справа и палитра команд. Освоив оболочку
один раз, вы работаете одинаково с данными, картами, документами и поручениями.

## Как начать

1. Откройте адрес установки в браузере. Экран **«Вход в систему»** с подписью
   **«Рабочая платформа организации»** (её и название организации задаёт
   администратор в брендировании).
2. Введите **«Логин или почта»** и **«Пароль»**, нажмите **«Войти»**.
   - Если организация подключила единый вход, рядом есть кнопка
     **«Войти через корпоративную учётную запись»** (название может быть своим).
   - Если вы завели ключ входа, есть кнопка **«Войти по ключу»**.
   - Кнопки видны только тогда, когда способ действительно настроен.
3. Если включён второй фактор — экран **«Подтверждение входа»**: шестизначный
   **«Код»** из приложения-аутентификатора, кнопка **«Подтвердить»**. Не под рукой
   телефон — **«Использовать код восстановления»**. Ключ входа подтверждается
   кнопкой **«Подтвердить ключом»**.
4. Вошли по временному паролю — система попросит **«Задайте свой пароль»**:
   «Вы вошли по временному паролю. Придумайте постоянный, чтобы продолжить
   работу». Пароль — не короче 12 символов.
5. Забыли пароль — **«Не удаётся войти?»** → **«Восстановление доступа»**: укажите
   логин или почту, придёт ссылка. Ответ всегда одинаков («Если учётная запись
   существует, ссылка отправлена на почту») — по нему нельзя узнать, есть ли
   такая учётная запись.

После входа открывается **«Мой день»**.

## Из чего состоит экран

**Рейка** (узкая полоса слева). Сверху — логотип организации, затем основные
разделы: **«Мой день»**, **«Данные»**, **«Карты»**, **«Документы»**, **«Файлы»**,
**«Задачи»**, **«Чаты»**, **«Встречи»**, **«Знания»**, **«Календарь»**. Внизу —
**«Поиск»** (открывает палитру команд), **«Входящие»** (со счётчиком дел),
**«Уведомления»** (со счётчиком непрочитанных), **«Ассистент»**,
**«Администрирование»** (только у администратора системы), **«Настройки»** и
аватар — он тоже ведёт в профиль. Разделы, выключенные администратором для всей
установки, с рейки исчезают.

Экраны, которых на рейке нет, открываются из палитры команд (`⌘K`): **«Формы
сбора»**, **«Алерты»**, **«Пайплайны»**, **«Территории»**, **«Пространства»**,
**«Контроль исполнения»**, **«Нагрузка»**, **«Корзина»**, **«Поиск»**.

**Навигатор** (слева от рабочей области) — разделы **«Избранное»**,
**«Пространства»**, **«Недавние»**; внизу — **«Новое пространство»** и корзина.
Поле **«Найти в навигаторе»** фильтрует только названия пространств.
Одновременно раскрыто одно пространство: раскрывая второе, первое свернётся.
Сворачивается панель кнопкой **«Свернуть навигатор»** (`⌘B`).

**Вкладки** — всё открывается вкладками. В меню вкладки: **«Закрепить»**,
**«Открыть в разделении»**, **«Закрыть остальные»**, **«Закрыть справа»**,
**«Восстановить закрытую вкладку»**. Вкладке можно назначить цвет группы
(синяя, оранжевая, зелёная, красная, фиолетовая) — панели одной группы делят
выделение строк, фильтр графика и охват карты по датасету («Связанные
представления»).

**Контекстная панель** справа (`⌘.`) — вкладки **«Инфо»**, **«Связи»**,
**«Обсуждение»**, **«Активность»**, **«Ассистент»** для открытого объекта. Без
открытого объекта — «Нет выбранного объекта».

**Строка состояния** внизу — число выполняющихся заданий, отметка «Вы замещаете:
<имя>», **«Горячие клавиши»**, **«Версия платформы»**.

**Палитра команд** — `⌘K`, поле **«Поиск объектов и команд…»**: группы
«Недавние», «Объекты», «Пространства», «Команды». `↑↓` выбрать, `↵` открыть,
`⌘↵` — в новой вкладке. Её же открывают кнопка **«Поиск»** на рейке, `⌘T` и
кнопка «+» в полосе вкладок, хотя подписаны они как «Новая вкладка».

## Пошагово: сохранить рабочее пространство и вернуться к нему завтра

1. Разложите вкладки так, как удобно (можно в двух панелях — **«Открыть в
   разделении»**, `⌘\`).
2. Меню **«Рабочие пространства»** → **«Сохранить вкладки как…»**.
3. В диалоге «Сохранить рабочее пространство» укажите **«Название»** (например,
   «Паводок-2026: карта и штаб»). Отметка **«Общее для пространства»** делает
   набор видимым всем участникам выбранного пространства.
4. Нажмите **«Сохранить»** — появится сообщение «Рабочее пространство «…»
   сохранено».
5. Дальше набор открывается из того же меню (**«Открыть»**), из виджета
   **«Продолжить»** на «Моём дне» или из палитры команд. Текущие вкладки можно
   записать поверх — **«Перезаписать текущими вкладками»**, а ошибочное открытие
   отменить кнопкой **«Вернуть прежние вкладки»**.

## Горячие клавиши

Полный список — кнопка **«Горячие клавиши»** в строке состояния или `Shift+?`.
Сочетания сравниваются по коду клавиши, поэтому кириллическая раскладка не
мешает.

| Что | Клавиши |
|---|---|
| Палитра команд | `⌘K` (и `⌘T`) |
| Навигатор / Контекстная панель | `⌘B` / `⌘.` |
| Закрыть вкладку / Восстановить закрытую | `⌘W` / `⌘⇧T` |
| Разделить панель | `⌘\` |
| Перейти к вкладке 1…9 / Следующая вкладка | `⌘1`…`⌘9` / `Ctrl+Tab` |
| Мой день / Входящие / Файлы | `G H` / `G I` / `G F` |
| Сохранить | `⌘S` |
| Поиск в представлении | `/` |
| Вниз / вверх по списку, открыть | `J` / `K` / `Enter` |
| Согласовать / Отклонить (Входящие) | `A` / `R` |
| Вставить в ячейки / Отменить правку / Повторить | `⌘V` / `⌘Z` / `⌘⇧Z` |
| Шпаргалка | `Shift+?` |

Две оговорки. Подсказки на кнопках рейки обещают `G D`, `G M`, `G O`, `G T`,
`G C` — эти сочетания не работают, открывайте разделы мышью. В шпаргалке есть
строки `⌘S`, `/`, `Enter`, `A`, `R`, у которых пока нет обработчиков; зато в
ней не упомянуты работающие `S` (отложить) и `E` (открыть) во Входящих и
клавиши календаря `T`, `N`, `P`, `D`, `W`, `M`, `C`.

## Частые вопросы

**Почему раздела, о котором мне говорили, нет на рейке?** Либо администратор
выключил эту возможность для всей установки (тогда экран отвечает «Возможность
выключена» — «Администратор выключил её для всей установки. Данные никуда не
делись и вернутся, когда возможность включат»), либо у вас нет прав на него.

**Вкладка пишет «Тип объекта пока не поддерживается».** Такой объект открывается
не отдельным экраном, а из своего раздела; сообщение честно говорит, что
специального представления для него нет.

**Как сменить тему или язык?** Профиль → «Внешний вид»: тема («Светлая»,
«Тёмная», «Системная»), плотность («Комфортная», «Компактная»), язык.

**Меня отключило и просит войти снова.** Сессия истекает по политике
безопасности организации («Сессия истекла, войдите заново»). Несохранённые
правки совместных документов (тетрадь, страница знаний, протокол) не теряются —
они сохраняются по ходу.

**Я вижу «Вы замещаете: …».** Вы работаете от имени коллеги, который назначил
вас заместителем. Все действия помечаются «от имени» и попадают в аудит.
