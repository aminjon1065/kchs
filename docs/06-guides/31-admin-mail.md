# Почта установки

Почта Комитета в составе установки (ADR-0150):
- почтовый сервер docker-mailserver и веб-почта Roundcube — профиль `mail`;
- ящик у каждого действующего сотрудника (`логин@домен`) и общий ящик канцелярии;
- исходящие документы уходят письмом из ящика канцелярии (ADR-0149), ответы приходят в
  очередь «Из почты».

## Включить на тестовом домене

Пока домена Комитета нет, почта работает на тестовом домене внутри установки. Письма между
сотрудниками и канцелярией ходят, наружу — нет.

В `.env`:

```
MAIL_DOMAIN=kchs.test
MAIL_HOSTNAME=mail.kchs.test
MAIL_WEBMAIL_URL=http://localhost:8083
# api и worker на хосте (разработка):
MAIL_CONFIG_VOLUME=../../.mail-config         # каталог настроек сервера, общий с платформой
MAIL_CONFIG_DIR=../../.mail-config             # тот же каталог — для api (путь от apps/api)
MAIL_SUBMISSION_URL=smtp://localhost:5587      # порт 587 сервера (MAIL_SUBMISSION_PORT)
MAIL_IMAP_HOST=localhost
MAIL_IMAP_PORT=9993
```

В установке целиком в контейнерах (`--profile app`) платформа и сервер делят том
`mailconfig` (подключён к api и worker как `/var/lib/kchs/mail`):
`MAIL_CONFIG_DIR_IN_APP=/var/lib/kchs/mail`, `MAIL_SUBMISSION_URL_IN_APP=smtp://mailserver:587`,
`MAIL_IMAP_HOST_IN_APP=mailserver`, `MAIL_IMAP_PORT_IN_APP=993`.

```bash
docker compose --profile mail up -d --wait
pnpm kchs mail sync          # в контейнерах: docker compose exec api kchs mail sync
```

`kchs mail sync` заводит ящик канцелярии и ящики сотрудников и пишет файл учёток. Кроме того,
он заводит интеграцию «Ящик канцелярии» для приёма в очередь «Из почты», если есть
делопроизводитель. Дальше файл переписывается сам: при новом сотруднике, блокировке и смене
пароля для почты.

## Сотруднику: вход в почту

**Профиль → «Почта»** → **«Получить пароль для почты»**.
- Пароль отдельный от пароля «Портала КЧС» и показывается один раз.
- Им входят в веб-почту («Открыть веб-почту») и в почтовую программу: IMAP — порт 993,
  отправка — 587, логин — адрес ящика.
- **«Новый пароль для почты»** заменяет прежний.
- **«Отозвать пароль»** закрывает вход: письма продолжают приходить.

Смена пароля пишется в журнал аудита.

Заблокированный сотрудник теряет вход сразу: его ящик пропадает из файла учёток, письма
ему не принимаются. Содержимое ящика остаётся на сервере.

## Канцелярия

- Пароль ящика канцелярии знает только платформа. Он зашифрован мастер-ключом и
  перешифровывается `kchs secrets rotate`.
- Делопроизводители работают с письмами канцелярии в очереди «Из почты», а не в
  веб-почте.
- Исходящий документ отправляется из карточки: «Отметить отправку» → способ «Эл. почта»
  ([06](06-user-documents.md)).
- Уведомление о недоставке, вернувшееся в ящик канцелярии, отмечает письмо «Вернулось» в
  карточке документа.

## Домен Комитета (при переносе на сервер)

1. **DNS:**
   - `MX kchs.tj → mail.kchs.tj`;
   - запись A для `mail.kchs.tj`;
   - SPF — `v=spf1 mx -all`;
   - DMARC — `_dmarc TXT "v=DMARC1; p=quarantine; rua=mailto:postmaster@kchs.tj"`.
2. **DKIM:**
   `docker compose --profile mail exec mailserver setup config dkim keysize 2048 domain kchs.tj`.
   Запись TXT для DNS — в файле `opendkim/keys/kchs.tj/mail.txt` каталога настроек сервера.
3. **Переменные:** в `.env` `MAIL_DOMAIN=kchs.tj`, `MAIL_HOSTNAME=mail.kchs.tj`.
4. **Сертификат.** Положите настоящий сертификат на `mail.kchs.tj` в `ssl/` каталога
   настроек вместо самоподписанного, затем задайте `MAIL_TLS_VERIFY=true` и уберите
   отключение проверки из `infra/compose/mail/roundcube.inc.php`.
5. **Порты.** `MAIL_BIND=0.0.0.0`, откройте 25, 587 и 993. Если провайдер закрывает
   исходящий порт 25 — `MAIL_RELAY_HOST=[smtp.провайдер]:587`.
6. **Синхронизация.** `kchs mail sync`: адреса ящиков сменятся на новый домен.

## Чего пока нет

- Ночная резервная копия установки не включает тома почты (`maildata`, `mailconfig`) —
  копируйте их средствами сервера.
- Входа в веб-почту через «Портал КЧС» без отдельного пароля (SSO).
- Общих папок и делегирования ящиков: ящик канцелярии — служебный, его разбирает очередь
  «Из почты».
- Антивируса и спам-фильтра: включаются переменными сервера `ENABLE_CLAMAV` и
  `ENABLE_RSPAMD`, когда почта откроется наружу.
