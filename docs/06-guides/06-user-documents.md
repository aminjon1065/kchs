# Документы: регистрация, согласование, подпись, дела

## Зачем это

Документооборот в Портале КЧС — это карточка документа с реквизитами, журналами
регистрации, маршрутом согласования и подписи, резолюциями, ознакомлением,
делами и печатными формами. Документ связан с поручениями, встречами, данными и
территориями: из резолюции сразу рождаются поручения, из протокола встречи —
документ.

## Как начать

Рейка → **«Документы»**. Слева — навигатор **«Разделы документов»**:

- **«Представления»**: «Все», «Мои», «На согласовании у меня», «Мои на контроле»,
  «На контроле», «Просроченные на контроле», «Просроченные», «К отправке»,
  «Журнал входящих {год}», «Черновики», «Архив» — со счётчиками;
- **«Канцелярия»**: «Из почты», «Номенклатура дел», «Поиск в архиве», «Дашборд
  „Канцелярия“»;
- **«Журналы»** — журналы регистрации со счётчиками;
- **«Справочники»**: «Журналы регистрации», «Корреспонденты», «Типы документов»,
  «Шаблоны документов».

Справа вверху — **«Зарегистрировать»** (для делопроизводителя) и **«Создать»**.

Карточка документа — семь вкладок: **«Карточка»**, **«Файлы и версии»**,
**«Маршрут»**, **«Резолюции и поручения»**, **«Связи»**, **«Ознакомление»**,
**«История»**. Действия живут не на вкладках, а в правой контекстной панели,
вкладка «Сведения», в секциях **«Действия»** и **«Делопроизводство»**; если
панель закрыта, в шапке появляется кнопка **«Действия»**.

## Пошагово: зарегистрировать входящий

1. **«Зарегистрировать»** — откроется вкладка **«Регистрация входящего»**.
2. Вверху выберите тип документа; справа видно **«Журнал: {название}»** — журнал
   берётся из типа.
3. Слева перетащите скан: «Перетащите скан или выберите файл» — «PDF,
   изображение или документ Word — откроется слева для сверки с карточкой».
   Первый скан заводит черновик документа и первую версию.
4. Справа заполните реквизиты: **«Тема»** (обязательна), «Краткое содержание»,
   **«Корреспондент»** (для входящего обязателен), «Исходящий номер отправителя»,
   «Дата отправителя», **«Дата поступления»**, «Способ доставки»,
   «Ответственный», «Подписант», «Срок», «Контроль», «Контролёр», **«Гриф»**.
   Ниже — **«Поля типа»**.
5. Если в установке настроен ИИ, над формой появится **«Помощник регистрации»**:
   кнопка **«Заполнить по скану»** предложит реквизиты с цитатой из текста и
   бейджем уверенности («уверенно · N %», «проверьте · N %», «сомнительно ·
   N %»). Каждое значение попадает в карточку только по кнопке **«Принять»** (или
   сразу все — **«Принять уверенные ({count})»**).
6. **«Зарегистрировать»**. Итог — «Зарегистрирован № {номер}», карточка
   открывается фоновой вкладкой, экран регистрации очищается под следующий
   документ. Если чего-то не хватает — «Проверьте обязательные поля карточки».

Исходящий и внутренний делаются иначе: **«Создать»** → диалог **«Новый
документ»** («Тип», при наличии — «Шаблон», «Тема») → черновик → когда документ
готов, кнопка **«Зарегистрировать»** в секции «Действия» карточки. В её диалоге
выбирается **«Журнал»** и при необходимости **«Номер из резерва»** — «Для
бумажного документа, номер которого выдан заранее».

Номер по умолчанию — «подразделение-дело/номер», например `03-12/145`: индекс
дела по номенклатуре и порядковый номер журнала. Поле **«Дело по
номенклатуре»** («Индекс дела идёт в номер; подобрано по типу документа и
подразделению») уже заполнено, строка «Номер будет: …» показывает итог — обычно
остаётся нажать **«Зарегистрировать»**. Можно выбрать другое открытое дело этого
года или **«Без дела»** — тогда вместо индекса дела в номере префикс журнала
(`ВХ/146`). Входящий на экране регистрации получает дело так же, по типу и
подразделению. Приказы и распоряжения нумеруются по порядку в году (`001-ПР/26`).
Выбранное дело видно в карточке — секция **«Дело по номенклатуре»** («Указано при
регистрации: после исполнения документ подшивается в него»).

## Согласование

1. Кнопка **«Отправить на согласование»** (в «Действиях» или на пустой вкладке
   «Маршрут») → диалог **«Отправить по маршруту»**.
2. **«Маршрут»** — список опубликованных маршрутов; у маршрута типа приписка
   «по умолчанию для типа».
3. Для шагов, где согласующих выбирает инициатор, появятся поля **«Кто
   согласует: {шаг}»**.
4. Секция **«Кто будет назначен»** показывает живой предпросмотр: шаги,
   назначенные и «Срок: {дата}». Шаг без людей помечается «Никто не назначен».
5. **«Отправить на согласование»** — «Документ отправлен по маршруту».

Если отправить нельзя, диалог объяснит: «Отправить документ по маршруту может
тот, кто вправе его править», «Документ в этом статусе по маршруту не
отправляется», «По документу уже идёт маршрут», «Приложите файл документа на
вкладке „Файлы и версии“: по маршруту идёт версия».

На вкладке **«Маршрут»** — линия маршрута: карточки шагов по кругам, у каждого
название, тип («Согласование», «Подпись», «Регистрация», «Ознакомление»,
«Доработка», «Поручение», «Уведомление» и др.), бейдж версии документа,
состояние («Идёт», «Просрочен», «Снят») или исход («Согласовано», «Отклонено»,
«Замечания», «Подписано», «Отказ в подписи», «Ознакомлены», «Зарегистрировано»),
срок и список назначенных с их состояниями.

**Ваше решение** появляется блоком над линией и в контекстной панели —
**«Ваше решение: {шаг}»** (или «Решение за {имя}: {шаг}», если решаете за
замещаемого). Кнопки: **«Согласовать»**, **«Замечания»**, **«Отклонить»**,
**«Подписать»**, **«Отказать в подписи»**, **«Ознакомлен»**,
**«Зарегистрировать»**, **«Отправить повторно»**, **«Отозвать»**. Отклонение,
отказ и отзыв требуют комментария; к замечаниям можно приложить файл с правками.
Если шаг это разрешает, доступны **«Передать»** и **«Добавить согласующего»**.

Отклонённый документ возвращается автору на доработку (дело «Доработать и
отправить повторно: …»). Пойдёт ли второй круг ко всем или только к
несогласовавшим, задано в маршруте; зачтённые согласия видны как «Засчитано».

Снять документ с маршрута — **«Отозвать с маршрута»**: «Маршрут остановится,
документ вернётся автору на доработку».

## Версии документа

Вкладка **«Файлы и версии»**: слева PDF-представление выбранной версии, справа
список **«Версии»** с бейджами «Текущая» / «Окончательная», состоянием PDF,
автором, примечанием, файлами («Основной», «Приложение») и контрольной суммой
SHA-256.

**«Новая версия»**: зона «Основной файл версии», «Приложения (необязательно)»,
«Примечание к версии» → **«Добавить версию»**. Пока идёт маршрут, версия
заморожена — новую можно добавить после возврата документа.

**«Сравнить»** (при двух и более версиях) открывает **«Сравнение версий»**:
«Было» / «Стало», **«Вид сравнения»** — «Текст» или «Рядом», статистика
«Добавлено слов: …, удалено: …».

## Подпись

В системе работает **простая электронная подпись**. Подписать можно только как
решение шага «Подпись» идущего маршрута — отдельной кнопки «Подписать» в карточке
нет. Подписант берётся из маршрута: в стартовых маршрутах это поле **«Подписант»**
карточки (для исходящего и приказа, с кодом второго фактора) либо руководитель
подразделения автора (для служебной записки).

Отметка о подписи — секция **«Подписи»** внизу вкладки «Маршрут»: кто и когда
подписал, номер версии, «подтверждена кодом», хэш SHA-256 подписанной версии и
бейдж состояния — **«Подпись верна»**, **«Хэш вычисляется»** или **«Файл изменён
после подписи»**. Печатная форма **«Лист подписи»** повторяет это на бумаге с
оговоркой о простой электронной подписи.

Квалифицированной подписи (УКЭП) нет: в конструкторе маршрутов такой вид выбрать
можно, но маршрут с ним не запускается. Оттиска подписи и гербовой печати тоже
нет.

## Резолюции и поручения

Вкладка **«Резолюции и поручения»**:

1. **«Наложить резолюцию»** (делопроизводитель, вносящий за руководителя, видит
   **«Внести резолюцию»**).
2. В диалоге: **«Шаблон»** готовых формулировок, **«Текст резолюции»**,
   **«Ответственный»**, **«Соисполнители»**, **«Срок исполнения»** (датой или в
   рабочих днях, 1…366), переключатель **«На контроле»** и **«Контролёр»**
   («Без выбора — контролёр документа, а если его нет — зарегистрировавший»).
3. **«Наложить резолюцию»** — «Резолюция наложена, поручения созданы».

У резолюции видны прогресс («Открыто {N} из {M}» или «Все поручения закрыты») и
список **«Поручения резолюции»**. Ответственный и соисполнители могут добавить
**«Вложенную резолюцию»** — срок у неё не позже родительского.

Есть также **«Направить на резолюцию»** (кому и до какого срока) и **«Не требует
исполнения»** — документ получает статус «Исполнен» без поручений.

## Ознакомление

Вкладка **«Ознакомление»**: **«Отправить на ознакомление»** → диалог «Кому»
(сотрудники, подразделения, группы), **«Срок ознакомления»**, переключатель
**«Отметка с кодом подтверждения»**, «Примечание». Тем, кого пропустили, видна
секция **«Не отправлено»** с причиной («нет допуска к грифу», «уже ждёт
ознакомления»).

Тому, кого знакомят, вверху показывается **«Вас просят ознакомиться с
документом»** и кнопка **«Ознакомлен»**. Сводка — «Ознакомлены {N} из {M}»,
просрочившие видны бейджем; кнопка **«Напомнить»** шлёт напоминание (не чаще
раза в час).

## Дела и архив

**«Подшить в дело»** (секция «Делопроизводство»): «Документ получит статус „В
деле“. Дело предложено по типу документа и подразделению» — подходящее дело
помечено бейджем **«Подходит»**; дело из номера документа стоит первым и уже
выбрано.

**«Номенклатура дел»** (навигатор → «Канцелярия»): фильтры по году и состоянию
(«Открыто», «Закрыто», «В архиве», «Уничтожено»), кнопки **«Новое дело»**,
**«Закрыть дела {год} года»**, **«Акт об уничтожении»**. У дела — «Индекс»,
«Заголовок», «Год», **«Срок хранения»** («Срок хранения исчисляется с 1 января
следующего года»), «Типы документов», «Кто подшивает». Действия: **«Закрыть
дело»**, **«Открыть снова»**, **«Передать в архив»**.

Утверждённую номенклатуру не нужно заводить по одному делу: **«Ещё»** →
**«Импорт из Excel»**.

1. **«Скачать образец»** — типовая номенклатура по подразделениям и лист «Как
   заполнять» со списками подразделений и типов документов. Столбцы: «Индекс»,
   «Заголовок дела», «Год», «Подразделение», «Срок хранения, лет» (число лет или
   «постоянно»), «Статья перечня, отметка», «Типы документов» (через «;»),
   «Примечание».
2. **«Выбрать файл»**, при необходимости — **«Год для строк без года»**.
3. **«Проверить»** — ничего не создаёт: у каждой строки итог «Готово», «Уже есть»
   (дело с таким индексом в этом году уже заведено — пропускается) или «Ошибка» с
   объяснением, что поправить.
4. **«Завести N дел»** — заводятся только готовые строки. Повторный импорт того же
   файла ничего не дублирует.

Архив отдельного экрана не имеет: есть представление **«Архив»** и **«Поиск в
архиве»** (общий поиск с фильтром по статусам).

## Переписка и связи

Вкладка **«Связи»**: сверху **«Переписка»** — цепочка «входящее → ответ → новое
входящее» по связям «в ответ на»; недоступные документы цепочки показываются
пунктиром. Кнопка **«Ответить»** заводит черновик исходящего со связью «в ответ
на».

Ниже — **«Связи документа»** по видам: «В ответ на», «Во исполнение»,
«Отменяет», «Изменяет», «Связан с», «Создан из», «О территории». Вручную
добавляются только первые пять — кнопка **«Связать с документом»**.

Отправку исходящего фиксирует **«Отметить отправку»**: «Адресат из справочника»
или свободным текстом, «Способ доставки», «Дата отправки», «Номер отправления».
Само письмо система наружу не шлёт.

## Печатные формы и грифы

Кнопка **«Печать»** в шапке карточки открывает меню **«Печатные формы»**:

| Форма | Где доступна |
|---|---|
| **«Лист согласования»**, **«Лист подписи»**, **«Лист ознакомления»** | у любого документа |
| **«Регистрационная карточка»**, **«PDF со штампом регистрации»** | только если ключ формы указан в типе документа (из коробки — у входящего письма) |
| **«Реестр отправки»** | в карточке журнала регистрации |
| **«Опись дела»** | в карточке дела |

Недоступная форма показывается серой с причиной: «Документ ещё не
зарегистрирован», «У документа нет файла», «PDF-представление ещё готовится»,
«Документ не подписан», «Ознакомление с документом не запрашивалось».

Готовые формы копятся в секции **«Печатные формы и шаблоны»** на вкладке «Файлы
и версии». Там же — селект шаблона и кнопка **«По шаблону»**: заполняет DOCX-шаблон
данными карточки и кладёт результат новой версией документа.

**Грифы**: «Общедоступно», «Для служебного пользования», «Конфиденциально».
Документ строже вашего допуска вам не виден. Грифа «Секретно» нет: сведения,
составляющие государственную тайну, в системе не обрабатываются. Файл с грифом
«Конфиденциально» и выше скачивается только копией с водяным знаком — отдельной
кнопки для этого нет, система готовит копию сама.

## Регистрация из почты

Экран **«Из почты»** (навигатор → «Канцелярия») доступен делопроизводителю.
Ящик настраивается не здесь, а интеграцией: «Ящик канцелярии настраивается
интеграцией „imap“ в администрировании».

1. **«Получить почту»** — «Забрано писем: {N}, заведено черновиков: {M}»
   (почта опрашивается и сама, по расписанию).
2. Слева — письма с состоянием «Черновик», «Зарегистрировано», «Отклонено», «Не
   разобрано»; справа — карточка письма с отправителем, текстом и вложениями.
3. Если корреспондента не нашли по адресу — «Не найден по адресу: {имя} —
   заведите корреспондента».
4. **«Зарегистрировать»** открывает уже заведённый из письма черновик документа —
   номер присваивается в его карточке. **«Отклонить»** требует причины.

## Интеллектуальные функции документа

Контекстная панель → вкладка **«Ассистент»** (если ИИ настроен):

- **«Краткое содержание»** — «ИИ перескажет документ в 3–5 предложениях»; кнопка
  **«Составить»**, затем **«Вставить в карточку»** или **«Копировать»**;
- **«Черновик ответа»** (только у входящих) — поле **«Что ответить»** и кнопка
  **«Подготовить черновик»**; результат копируется, автоматически он никуда не
  записывается.

Если функция недоступна, причина пишется прямо: «ИИ не настроен на этой
установке», «Гриф документа не позволяет отправлять его текст ИИ — заполните
вручную», «У документа нет файла — прикрепите скан или версию», «Распознаём текст
скана…», «Текст файла не распознан — заполните карточку вручную».

## Чего пока нет

- Нет квалифицированной электронной подписи, факсимиле и гербовой печати.
- Нельзя подписать документ вне маршрута и нельзя вручную сменить статус
  документа — статусы меняют только действия и движок маршрутов.
- Нет отправки исходящего по почте из системы (IMAP работает только на приём).
- Нет массовых операций над документами в списке.
- Нет штрихкодов и сканирования из интерфейса — скан прикладывается файлом.
- Конструктор маршрутов обычному пользователю недоступен: он в администрировании.

## Частые вопросы

**Документ зарегистрирован, а штампа нет.** Штамп и регистрационная карточка
строятся только для типов, у которых эти печатные формы перечислены в настройках
типа. Из коробки это входящее письмо; для других типов ключ добавляет
администратор.

**Почему нельзя добавить новую версию?** Пока документ идёт по маршруту, версия
заморожена: согласующие видят ровно тот файл, который им отправили. Верните
документ на доработку — версия разблокируется.

**Кто может внести резолюцию за руководителя?** Делопроизводитель с
соответствующим правом; в диалоге появляется поле **«От имени руководителя»**, и
факт внесения записывается в журнал аудита.

**Что значит «Файл изменён после подписи»?** Хэш подписанной версии не совпадает
с файлом: файл заменили после подписи. Подпись остаётся привязанной к своей
версии — её видно в секции «Подписи» и в листе подписи.
