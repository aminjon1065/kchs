# Данные: импорт, исследование, дашборды

## Зачем это

Данные — центр платформы. Таблица, график, карта, показатель и отчёт — разные
представления одного датасета. Загрузив файл один раз, вы получаете таблицу с
владельцем, схемой, версиями, историей строк, правами на строки и столбцы, а
дальше строите по ней запросы, графики, дашборды и карты.

## Как начать

Рейка → **«Данные»**. Экран — каталог: полоса пространств, список объектов
(датасеты, графики, дашборды, показатели, тетради, отчёты) со столбцами
**«Название»**, **«Строк»**, **«Качество»**, **«Обновлён»**.

В шапке каталога — **«SQL-лаборатория»** (если есть соответствующая
способность), **«Показатель»**, **«Дашборд»**, **«Тетрадь»**, **«Отчёт»** и
основная кнопка **«Загрузить файл»**.

Экраны **«Пайплайны»** и **«Алерты»** на рейке не показываются — открываются из
палитры команд (`⌘K`).

## Пошагово: загрузить файл и получить датасет

1. **«Загрузить файл»** (или перетащите файл в пустой список). Форматы: «CSV,
   TSV, Excel, JSON, GeoJSON, Shapefile (zip), GeoPackage, KML/KMZ, GPX — до
   2 ГБ».
2. Мастер **«Импорт данных»** из четырёх шагов: **«Файл» → «Структура» →
   «Сопоставление» → «Проверка и запуск»**.
3. **«Структура».** Видны формат, число строк и столбцов; для гео-файла —
   «Геометрия: …» и охват. Здесь же — **«Лист»** (Excel), **«Кодировка»**,
   **«Разделитель»**, **«Пропустить строк сверху»**, **«Строк заголовка»**,
   **«Десятичный знак»**, **«Порядок даты»**, **«Слой»** и **«Система
   координат»** для геоданных. После правок нажмите **«Применить»** — файл
   разберётся заново. Ниже — таблица «Первые строки файла».
4. **«Сопоставление».** Таблица столбцов: флажок **«Загружать»**, **«Подпись»**,
   **«Ключ поля»**, **«Тип»**, **«Семантика»**, флажок **«Ключ»** и примеры
   значений. Типы система предлагает сама — по 2000 строкам выборки; значения,
   не подходящие под тип, помечаются («N значений не подходят»). Для импорта в
   существующий датасет выбирается **«Режим загрузки»**: «Заменить все строки»,
   «Добавить строки», «Обновить по ключу и добавить новые», «Синхронизировать по
   ключу (отсутствующие — удалить)».
5. **«Проверка и запуск».** Сводка, список значений, которые не подойдут по типу,
   и выбор **«Если в строках есть ошибки»**: «Загрузить корректные строки, ошибки
   — в отчёт» (по умолчанию) или «Ничего не загружать». Нажмите **«Запустить
   импорт»**.
6. Импорт идёт в фоне («Импорт продолжится в фоне — ход виден в строке
   состояния»). Итог: «Добавлено … · обновлено … · удалено … · ошибок …» и
   таблица **«Ошибки в строках»** («Строка», «Поле», «Значение», «Причина»).
   Кнопка **«Открыть датасет»**.

Для режимов «Обновить по ключу» и «Синхронизировать» можно включить **«Показать
изменения перед публикацией»**: перед записью появится экран **«Изменения перед
публикацией»** с плитками «Добавится», «Изменится», «Удалится», «Без изменений»
и примерами «было → стало»; дальше — **«Опубликовать»** или **«Отменить
импорт»**.

## Карточка датасета

Шапка: название (правится по месту), бейдж версии, «{n} строк», «Последний импорт
…». Кнопки — **«Спросить данные»**, **«Исследовать»**, **«Импорт»**,
**«Поделиться»**, **«Удалить»**; у датасета с геометрией ещё «Показать на карте»,
**«Анализ»** и хороплет.

Вкладки: **«Таблица»**, **«Схема»**, **«Версии»**, **«Импорты»**, **«Качество»**,
**«Доступ»**.

**«Таблица».** Поиск по таблице, сортировка щелчком по заголовку, управление
столбцами, кнопка **«Строка»** (добавить), **«Экспорт»**, **«Обновить»**.
Под панелью — фильтры по столбцам: кнопка **«Фильтр»** (поле → условие →
значение → **«Применить»**) или пункт **«Фильтр по столбцу»** в меню столбца —
условие сразу по этому полю. Условия видны чипами над таблицей (щелчок —
изменить, крестик — убрать, **«Сбросить фильтры»** — все), у столбца под фильтром
в шапке — значок фильтра; **«Расширенный режим»** собирает группы «или».
Ячейки правятся на месте, если датасет это разрешает; вставка из буфера
добавляет строки пачкой (до 1000). Если строку уже изменил другой человек,
появится «Строку уже изменили — показаны её текущие значения». Enter или двойной
щелчок открывает карточку строки с вкладками **«Поля»**, **«История»**,
**«Поручения»**.

**«Схема».** Список полей («Поле», «Ключ», «Тип», «Семантика», «Свойства») и
панель поля справа с вкладками **«Профиль»** и **«Свойства»**. Здесь задаются
подпись, семантика, единица, знаки после запятой, обязательность, индекс,
чувствительность и справочник; тип поля меняется через **«Сменить тип»** с
предварительной проверкой. **«Настройки таблицы»** задают **«Поле времени»**,
**«Ключ строки»**, **«Строки можно править в таблице»**, **«Вести историю
изменений строк»** и **«Срок хранения истории, дней»**: пусто — история хранится
бессрочно, у датасетов лент по умолчанию 90 дней. Версии старше срока удаляются
ночью, и откатить к ним уже нельзя. Если таблицу в этот момент читает долгий запрос
или выгрузка, правка схемы ответит «Датасет сейчас занят» — повторите через
несколько секунд.

**«Версии».** Каждый импорт и правка создают версию. У версии — происхождение
(«Создание», «Импорт», «Правка», «Откат», «Изменение схемы», «Анализ»), автор,
число строк и «+добавлено · изменено · −удалено». Кнопка **«Откатить»** доступна
управляющему; откат возможен не всегда — система объясняет почему (например,
«импорт в режиме „заменить“ не хранит прежних значений» или «история строк этой
версии удалена по сроку хранения»).

**«Импорты».** Журнал загрузок со статусами «В очереди», «Разбор», «Сравнение»,
«Ждёт публикации», «Загрузка», «Выполнен», «Ошибка», «Отменён».

**«Качество».** Правила датасета и их результат. Виды правил: «Значение
обязательно», «Значения не повторяются», «Число в диапазоне», «Соответствие
шаблону», «Значение из набора», «Есть в справочнике», «Геометрия корректна»,
«Данные свежие», «Строк не стало меньше». Кнопка **«Проверить сейчас»**;
проверка идёт и сама — при каждой новой версии. Итог виден бейджем («Не
проверялось», «Качество в норме», «Есть замечания», «Есть нарушения») и
отдельным столбцом **«Качество»** в каталоге.
Оговорка: в конструкторе правил задаются только «Ключ», «Вид», «Поле» и
«Важность». Правила, которым нужны параметры (диапазон, шаблон, набор значений,
справочник, срок свежести), сохранятся, но проверка вернёт ошибку — пока
работоспособны «Значение обязательно», «Значения не повторяются», «Геометрия
корректна» и «Строк не стало меньше».

**«Доступ».** Политики строк и столбцов: «Политики уточняют, какие строки и поля
видят пользователи с доступом ниже „Управление“. Владелец и управляющие видят
всё». В условиях доступны подстановки `@me`, `@my_unit`, `@my_units`,
`@my_territories`; столбцы можно **«Скрыть»** или **«Маскировать»**.

## Исследование

Кнопка **«Исследовать»** на датасете открывает вкладку «{Датасет} — Исследование».

**Обзор датасета** — то, что видно сразу:

- **шапка** — строк, полей, период данных (по полю даты), заполненность, когда данные
  обновлены и какая версия;
- **«С чего начать»** — готовые вопросы по полям датасета:
  - «Динамика по месяцам»;
  - «Чаще всего: … топ-10»;
  - «Где больше всего» и «На карте» — по территории;
  - «Год … к предыдущему»;
  - «Сумма и среднее» числового поля.

  Нажмите вопрос — справа появится ответ, а слева план, который можно править;
- **«Поля датасета»** — карточка на каждое поле:
  - у чисел и дат — распределение и среднее;
  - у справочных и текстовых полей — частые значения с долями;
  - у всех — доля пустых.

  Нажмите карточку, чтобы исследовать поле.

Кнопка **«Свой запрос»** начинает с разумного плана: количество по месяцам или топ по
району. Кнопка **«Обзор датасета»** в панели возвращает обзор.

**Конструктор слева:**

- **«Фильтры»**;
- **«Разрезы»** — у поля даты появляется **«Интервал»**: «Год», «Квартал», «Месяц»,
  «Неделя», «День», «Час»; у поля-территории — **«Уровень территории»**: «Как в данных»,
  «Область», «Район», «Джамоат» (районы складываются в свою область, джамоаты — в район);
- **«Меры»**:
  - функция: «Количество», «Различных», «Сумма», «Среднее», «Минимум», «Максимум»,
    «Медиана», «Формула»;
  - у каждой меры — **«Расчёт»**: «Доля от итога», «Накопительный итог», «Ранг»,
    «Изменение к предыдущему», «Изменение к предыдущему, %». Накопительный итог и изменение
    идут по порядку первого разреза. При сравнении периодов расчёт идёт от значения текущего
    периода;
- **«Сравнение периодов»** — кнопка **«Сравнить периоды»**:
  - поле даты и периоды: «Месяц к предыдущему», «Квартал к предыдущему», «Год к
    предыдущему», «С начала года к прошлому году» или «Свои даты»;
  - периоды отсчитываются от последней даты в данных, сравнивается последний полный период;
  - каждая мера даёт четыре столбца: «· текущий», «· база», «· разница», «· изменение»;
  - над результатом — подпись периодов;
- **«Сортировка»**, **«Лимит строк»**.

**Результат справа** переключается: **«График»**, **«Таблица»**, **«Карта»**.

- У графика можно выбрать вид: «Столбцы», «Линия», «Области», «Круговая», «Кольцо»,
  «Таблица», «Число», «Точки», «Тепловая карта», «Дерево», «Воронка».
- В таблице щелчок по заголовку сортирует весь результат. Строка **«Итого»** считает меры по
  всем данным плана, а не складывает видимые строки.
- **«Карта»** строит хороплет по полю-территории разреза или по геометрии датасета. Уровень —
  «Области», «Районы», «Джамоаты»; значение — первая мера. Если в датасете есть поле-точка,
  над картой переключатель **«Территории» / «Точки»**: «Точки» показывают сами места (до
  5000 строк с фильтром плана), близкие точки собраны в кружки с числом — приблизьте карту,
  и они распадутся.

**Детализация.** Щёлкните столбец графика или дважды щёлкните строку таблицы. Появится
панель «Выбрано: …»:

- **«Оставить только это»** добавляет фильтр. Область оставляет и все свои районы;
- **«Уровнем ниже: Районы»** (у разреза с уровнем территории) — оставляет выбранную область и
  раскрывает её районами; у района — джамоатами;
- **«Разбить по…»** — фильтр и новый разрез;
- **«Показать строки»** — первые 200 строк за элементом и кнопка «Открыть датасет».

Если результат пуст, экран объясняет почему и предлагает выход. «Фильтр отсёк все строки» —
кнопка **«Убрать фильтр»**. «В периодах сравнения нет строк» — экран показывает, за какие
даты данные есть. Ошибка запроса объяснена простыми словами, кнопка **«Начать заново»**
сбрасывает план.

Кнопка **«Сохранить как график»** заводит объект-график. Меню **«Ещё действия»**:

- **«В тетрадь…»** — ячейка с этим запросом в новую или существующую тетрадь;
- **«На дашборд…»** — плитка-график на выбранный дашборд;
- **«Как датасет…»** — из шагов исследования создаётся пайплайн и сразу запускается: первый
  прогон создаёт датасет, следующие пересчитывают его (вкладка пайплайна открывается сама).
  Расчёты над мерами, сортировка и лимит в датасет не переносятся — окно об этом скажет;
- **«Как показатель…»** — показатель из выбранной меры: фильтр исследования — его условия,
  разрезы — допустимые разрезы. Период и цели настраиваются в карточке показателя;
- **«Показать запрос»** — шаги запроса.

Внизу — «{n} строк · {ms} мс», при попадании в кэш — «из кэша», при расчёте в колоночной
копии — «считал движок».

Кнопка **«Экспорт»** рядом с «Сохранить как график»: **«Данные — CSV»**,
**«Данные — Excel (XLSX)»** (нужна способность «Выгрузка данных») и
**«Картинка — PNG»** (кадр графика на экране; у вида «Таблица» и «Число» картинки
нет). Данные считаются заново с вашими правами, подписи столбцов — как на
экране; больше 100 000 строк в файл не войдёт — система предупредит. Та же кнопка
есть на сохранённом графике.

**«Спросить данные»** (если в установке настроен ИИ): полоса над результатом,
поле **«Вопрос к данным»** («Например: сколько обращений по районам за 2025
год»), кнопка **«Спросить»**. Модель строит не SQL, а план конструктора — он
ложится в левую панель, и его можно править дальше. Рядом — счётчик «Сегодня:
{использовано} из {лимит} вопросов» и пояснение **«Как понят вопрос»** с кнопкой
**«Показать запрос»**.
Кнопка **«Спросить данные»** в шапке датасета просто открывает «Исследование» —
поле вопроса находится уже там.

**SQL-лаборатория** (нужна способность «SQL-лаборатория»): поле **«Запрос SQL»**,
кнопка **«Выполнить»** (`⌘Enter`; выделенный фрагмент выполняется отдельно),
панель датасетов с полями, история запросов. Политики доступа применяются
автоматически: «вы видите только свои строки и поля».

## Показатели

**«Показатель»** в каталоге → **«Новый показатель»**: «Название», «Датасет» (или
системный — задачи, поручения, документы, встречи, события, территории),
**«Мера»** (функция и поле или выражение), **«Условия»**, «Поле времени»,
«Период», «Сравнение», **«Разрезы»**, «Единица», «Знаков после запятой»,
**«Что лучше»** («Больше» / «Меньше» / «Всё равно»), **«Цели»** и **«Пороги»**
(«Норма», «Внимание», «Критично»).

Карточка показателя: выбор **«Период»** и **«Сравнение»**, крупное значение,
карточка **«История»** (с отметками срабатываний алертов), **«Разрез»**,
**«Определение»** и **«Где используется»**.

## Алерты

Экран **«Алерты»** (палитра команд, `⌘K`): «Правило на показатель: условие,
разрез, расписание проверки и каналы».

1. **«Создать алерт»** → «Название», «Пространство», **«Показатель»**,
   **«Условие»** → алерт создаётся **выключенным**.
2. В карточке — **«Когда сообщать»**: **«Порог»** (сравнение и значение),
   **«Изменение»** (направление и проценты) или **«Аномалия»** (**«Порог
   отклонения, σ»** и **«Сезонность»**), плюс **«Разрез»** (не более двух полей).
3. **«Расписание и доставка»**: **«Расписание проверки»** (cron), **«Период
   тишины, мин»**, **«Получатели»** (язык назначений: `user:…`, `role:…`,
   `unit_head(…)`), **«Каналы»** — «Уведомление», «Входящие», «Письмо».
4. **«Сохранить»**, затем **«Тестовый прогон»** (ничего не рассылает) или
   **«Проверить сейчас»**. Результат: «Сработало {N} из {M}» с причиной по
   каждой группе.
5. Включите переключатель **«Проверка включена»**.

Внизу карточки — **«История срабатываний»**. Если получатели не заданы,
уведомление уходит владельцу алерта.

## Тетради и дашборды

**Тетрадь** — холст исследования, который правят вместе. Создать:
**«Тетрадь»** в каталоге. Слева — **«Оглавление»**, сверху — **«Параметры
тетради»** («Период» и «Территория», общие для всех ячеек). Ячейки:
**«Текст»**, **«Запрос»** (конструктор или SQL), **«График»**, **«Показатель»**,
**«Вопрос ИИ»**, **«Карта»**; до 200 ячеек. Правки соавторов видны сразу,
состояние показывается в шапке («Сохраняется…», «Все изменения сохранены», «Нет
связи — правки сохранятся при подключении»). Кнопка **«В отчёт»** переносит
содержимое в новый отчёт — это и есть способ напечатать тетрадь.

**Дашборд** — сетка плиток. Создать: **«Дашборд»** в каталоге. В режиме
**«Изменить»** добавляются **«Плитка»** (виды: «График», «Показатель», «Карта»,
«Текст») и **«Фильтр»** («Значения», «Текст», «Период», «Территория»), у плитки
настраиваются ширина, высота и привязка фильтров. Щелчок по элементу графика
открывает панель **«Строки элемента графика»** с кнопками «Фильтр дашборда: …»
и «Открыть датасет». Режим **«TV»** — для экрана в зале.

У плитки-графика в заголовке — кнопка **«Экспорт»**: данные плитки с текущими
фильтрами дашборда (CSV, Excel) и картинка PNG. Кнопка **«Печать и PDF»** в шапке
дашборда открывает в новой вкладке лист печати: плитки той же сеткой на
альбомном листе A4, фильтры — как на экране, дата формирования. Окно печати
откроется само — выберите принтер или **«Сохранить как PDF»**. Фильтры дашборда к
картам на листе не применяются — лист об этом предупреждает.

## Происхождение и влияние

Контекстная панель → вкладка **«Связи»**, внизу: **«Откуда данные»** и **«Где
используется»**. Граф показывает только то, что вам видно; при обрыве цепочки —
«Показаны ближайшие связи — дальше цепочка продолжается». Загрузка файла в этот
граф не попадает — происхождение «файл → датасет» видно на вкладке «Импорты».

## Колоночная копия (для больших датасетов)

Если администратор включил колоночный слой, крупные датасеты получают копию в
Parquet, и тяжёлые сводки по ним считает движок — заметно быстрее. Пользователю
это видно в двух местах: карточка **«Колоночная копия»** на вкладке «Версии»
(статус, «Собрана», «Размер», «Строк», «Время сборки», кнопка **«Пересобрать»**)
и отметка **«считал движок»** в строке результата «Исследования» и ячейки
тетради. Геометрия в копии не хранится — карты и пространственные запросы всегда
считает основная база.

## Экспорт

Кнопка **«Экспорт»** на вкладке «Таблица» (нужна способность «Выгрузка данных»):
**«Табличные форматы»** — CSV, Excel, JSON; **«Геоформаты»** (если есть
геометрия) — GeoJSON, GeoPackage, Shapefile, KML. **«Что выгрузить»**: «Как в
таблице» (фильтры по столбцам, поиск, сортировка и видимые столбцы) или «Все
строки и все поля». Выгрузка учитывает ваши права; файл
хранится 30 дней; больше миллиона строк за раз не выгружается.

## Чего пока нет

- Нельзя сохранить запрос «Исследования» как самостоятельный объект: сохраняется
  график (вид «Таблица» — график-таблица с тем же запросом), датасет через пайплайн или
  показатель; снова открыть их в конструкторе нельзя.
- Тетрадь печатается только через отчёт (кнопка «В отчёт»); лист печати дашборда
  PDF-файлом по расписанию не рассылается — для рассылки нужен отчёт.
- Геометрию нельзя править в таблице и в карточке строки — только на карте.
- Внешние базы подключает администратор (раздел «Источники данных»); из ГИС-службы
  данные выгружаются файлом GeoJSON и дальше идут обычным мастером импорта.

## Частые вопросы

**Импорт закончился, но часть строк не загрузилась.** Это режим «Загрузить
корректные строки, ошибки — в отчёт». Причины — в таблице «Ошибки в строках» и в
файле отчёта: «не число», «не дата», «неверная геометрия», «повтор ключа —
оставлена последняя строка», «нет такой территории в справочнике» и так далее.

**Удалил строку — можно вернуть?** Строка помечается удалённой и остаётся в
истории; если история строк включена, прежние значения видны на вкладке
«История» карточки строки. Ключ удалённой строки свободен: можно добавить новую
строку с тем же ключом. Повторная загрузка файла «по ключу» вернёт удалённую
строку, если живой строки с этим ключом нет.

**Почему я вижу не все строки?** На датасете могут действовать политики строк.
Посмотреть, почему именно так, можно через «Поделиться» → «Почему есть доступ».

**Дашборд не даёт добавить плитку.** Нужен уровень «Редактирование» на дашборде,
а сам график, показатель или карта должны быть уже сохранены в пространстве.
