# Сквозные контракты

Контракты — JSON-структуры, которыми обмениваются модули, клиент и сервер, движок и хранилище. Они определяют целостность продукта. Реализация — zod-схемы в `packages/contracts` (и `packages/query`, `packages/chart-spec`, `packages/map-style`, `packages/process`), из которых выводятся типы TypeScript, JSON Schema для Python-движка и документация.

| Контракт | Файл | Где используется |
|---|---|---|
| Типы полей и фильтры | `field-types.md` | схемы датасетов, карточки документов, поля задач, формы, FilterBuilder, политики |
| QuerySpec и язык выражений | `query-spec.md` | конструктор, графики, показатели, тайлы, экспорт, ИИ |
| ChartSpec | `chart-spec.md` | графики, дашборды, тетради, отчёты |
| LayerStyle | `layer-style.md` | слои, легенды, печать |
| ProcessDefinition | `process-definition.md` | маршруты документов, модерация правок, ознакомление, автоматизации с ожиданием |
| AutomationRule | `automation-rule.md` | правила |
| Событие (конверт) | `events.md` | outbox, шина, вебхуки, realtime |

Правила изменения: любое несовместимое изменение — новая `version` в схеме + миграция сохранённых документов + ADR. Совместимые добавления (новые необязательные поля) — без версии, с обновлением документа.

Статус всех контрактов: **Решено** по структуре; перечни операторов/функций/типов графиков могут расширяться.
