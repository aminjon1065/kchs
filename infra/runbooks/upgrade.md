# Обновление установки

## Перед обновлением

1. Прочитать изменения релиза и записи ADR, добавленные с прошлой версии.
2. Убедиться, что резервная копия свежая **и проверенная**: в списке копий есть
   удачный прогон за последние сутки и отметка «проверено восстановлением» за
   последний месяц (`restore.md`, §«Ежемесячная проверка»). Непроверенная копия —
   это не копия, а надежда.
3. Проверить, что зелёные последние прогоны «Безопасность: образы и ZAP» и
   «Установка в контейнерах» на `main`: если Trivy нашёл уязвимость в образе или
   ZAP — новое замечание, обновляться на такой образ незачем.
4. Предупредить пользователей через «Объявления» в администрировании.

## Порядок

```bash
git fetch --tags && git checkout v0.<фаза>.<патч>
docker compose --profile app pull            # либо build при локальной сборке
pnpm db:migrate                              # миграции идемпотентны и защищены advisory lock
docker compose --profile app up -d
```

Миграции применяются автоматически при старте `api` (advisory lock не даст двум
инстансам мигрировать одновременно), команда выше нужна только при раздельном
развёртывании.

## Проверка после обновления

- `curl -fsS http://localhost:3000/health` → `{"status":"ok"}`;
- «Здоровье системы»: postgres, redis, meilisearch, storage — «Работает»;
- outbox без отставания (`Неопубликованных событий: 0`);
- вход, «Мой день», открытие объекта, обсуждение — вручную или `pnpm e2e`;
- заголовки установки на месте (их ставит Caddy, и правка Caddyfile или
  переменных окружения способна их потерять):

  ```bash
  curl -sD- -o /dev/null https://<узел>/ | grep -iE \
    'content-security-policy|x-frame-options|strict-transport|x-content-type|permissions-policy|cross-origin-opener'
  ```

  Ожидается строгий CSP с nonce, `X-Frame-Options: DENY`, HSTS, `nosniff`,
  `Permissions-Policy` и `Cross-Origin-Opener-Policy: same-origin`. Полная
  проверка — `bash infra/security/zap-baseline.sh` с
  `KCHS_ZAP_TARGETS=https://<узел>` (пассивное сканирование, безопасно для
  рабочей установки; список разобранных правил — `infra/security/zap-baseline.conf`);
- внутренние маршруты снаружи не видны: `curl -s -o /dev/null -w '%{http_code}'
  https://<узел>/api/v1/internal/office/x/content` → `404`.

## Откат

1. Вернуть предыдущий тег образов и поднять их.
2. Если новая версия применила необратимую миграцию — восстановить базу по
   `restore.md` на момент до обновления.

Каждая миграция обратима либо сопровождается планом отката; необратимые
изменения помечаются в описании релиза.
