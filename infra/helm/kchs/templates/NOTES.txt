{{- if .Values.init.enabled }}

Первый администратор ({{ .Values.init.adminLogin }}) создан заданием `kchs init`.
Временный пароль — в журнале задания, он печатается один раз:
  kubectl -n {{ .Release.Namespace }} logs job/{{ include "kchs.fullname" . }}-init
{{- else }}

Первая установка: создайте администратора одной командой —
  kubectl -n {{ .Release.Namespace }} run kchs-init --rm -it --restart=Never \
    --image={{ include "kchs.image" (dict "ctx" . "image" .Values.api.image) }} \
    --overrides='{"spec":{"containers":[{"name":"kchs-init","image":"{{ include "kchs.image" (dict "ctx" . "image" .Values.api.image) }}","command":["kchs","init"],"envFrom":[{"configMapRef":{"name":"{{ include "kchs.configMapName" . }}"}}]}]}}'
  — либо `init.enabled=true` в значениях.
{{- end }}
