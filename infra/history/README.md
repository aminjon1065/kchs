# История ЧС Комитета: разбор исходников и загрузка

Исторические данные Комитета 1988–2026 годов попадают в платформу в два шага (ADR-0194):

1. **Разбор** (`build-bundle.sh`, Python в образе движка). Исходники читаются, ничего в них не
   меняется. На выходе — файл сверки для владельца и каталог загрузки.
2. **Загрузка** (`kchs import-history`, сервисы платформы). Данные ложатся в пакет ЧС: реестр
   объектов, журнал аудита, события — как при работе через интерфейс. Повторный запуск
   досоздаёт только недостающее.

## Исходники

| Что | Где в папке Комитета | Что из этого получается |
|---|---|---|
| Реестр бедствий 1992–2020 (Excel, несколько версий файлов) | `Disaster+/` | «Происшествия» пакета ЧС |
| Акты оценки ущерба комиссий 2013–2026 (Word) | `ЧС/<год>.docx` | «Оценка ущерба от ЧС», события 2021–2026 |
| Сводка «10 сола» 2013–2024 (Excel) | `10 сола 2013-2024.xlsx` | «Статистика ЧС «10 сола»» |
| Геобаза ArcGIS «Карта связи КЧС и ГО» | `Tajikistan data/Data.gdb` | 13 слоёв и карта |
| Проекты ArcMap, печатные карты, рельеф, база ESTJ | там же, `*.bak` | архив файлов |

## Разбор

```bash
bash infra/history/build-bundle.sh ~/kchs-data ~/kchs-import
```

Шаги (каждый — отдельный скрипт, их можно запускать по одному):

| Скрипт | Что делает |
|---|---|
| `disaster.py` | версии файлов Disaster → один реестр: колонки по заголовкам, дубли версий, даты с точностью, время из описания, погибшие из текста (1992–2016), районы и виды |
| `damage.py` | акты Word → блоки по районам: решение комиссии, дата и вид бедствия, повреждения, итог; события 2021–2026 |
| `gis.py` | слои геобазы → GeoPackage EPSG:4326, 2D |
| `review.py` | классификатор, сводка «10 сола», `Сверка.xlsx` |
| `bundle.py` | каталог загрузки `bundle/`: `manifest.json`, `data/*.json`, `gis/*.gpkg`, `archive/**` |

Общие правила — `common.py`:

- **Старые таджикские буквы** (`њ ї ѓ ќ љ ў` из старых шрифтов) заменяются на `ҳ ӣ ғ қ ҷ ӯ`.
- **Районы** сопоставляются со справочником территорий платформы
  (`apps/api/src/seed/territories.json`), в том числе по старым названиям: Джиргатал → Лахш,
  Ганчи → Деваштич, Колхозобод → Дж. Балхи и т. д. «Бохтар» до 2018 года — Бохтарский район
  (ныне Кушониён), с 2018-го — город. Неузнанный район — область; без места — республика с
  замечанием.
- **Виды бедствий** сводятся к классификатору пакета ЧС с расширениями. Сочетание «дожди, сели»
  относится к главной опасности по порядку правил (`RULES`). Исходное написание сохраняется.
  У каждого вида есть категория официальной сводки «10 сола».

## Сверка

`Сверка.xlsx` — для владельца, до загрузки:

- как написания вида и района сведены к классификатору и справочнику;
- дубли версий файлов;
- сравнение с «10 сола» по годам и категориям;
- акты без суммы или даты;
- строки без года.

## Загрузка

На стенде показа:

```bash
bash infra/scripts/demo-stand.sh history ~/kchs-import/bundle
```

В установке: скопировать каталог в контейнер api и вызвать
`kchs import-history <каталог>`. Нужны работающие api, worker и движок: слои идут обычным
импортом файла. Команда с хоста против установки берёт адреса служб из `.env` (`KCHS_ENV_FILE`).

Что делает загрузка (`apps/api/src/seed/history/index.ts`):

1. Ставит пакет ЧС, если его нет: реестры, классификатор, карта и дашборды штаба, без
   демо-строк. Справочник территорий загружается, если он пуст.
2. Классификатор: виды пакета получают уточнённые названия, таджикское имя и категорию
   сводки, новые виды добавляются.
3. «Происшествия»: поля истории и строки. На время загрузки у реестра выключены события строк:
   иначе правила пакета разослали бы уведомления и поручения по каждому историческому
   событию с погибшими. После загрузки они снова включены. Точка события — центр района
   (`location_approx`). Описание длиннее 1000 символов целиком лежит в «Полном тексте».
4. «Оценка ущерба от ЧС (акты комиссий)» и «Статистика ЧС «10 сола» (официальная)» — новые
   реестры в «Общем».
5. Архив исходных файлов — папка «Архив данных КЧС 1988–2026» в «Общем».
6. Слои геобазы: импорт файла (движок нормализует, worker загружает), затем слой и карта
   «Карта связи КЧС и ГО». Карта «История ЧС 1988–2026» показывает происшествия.
7. Дашборд «История и статистика ЧС»: официальные цифры — из «10 сола», реестр — рядом.

Объекты находятся по ключам пакета (`meta.packKey = emergency.history.*`), строки — по
первичным ключам. Поэтому повторный запуск после исправленного разбора догружает только новое.
Изменённые строки он не перезаписывает.
